### Cockpit Definition - Internetlink

Mit dem Element "Internetlink" kann ein Verweis auf eine Internetseite erstellt werden. Dadurch kann mit einem einfachen Klick die gewünschte Seite im Browser aufgerufen werden.

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_340.png)

Die folgenden Einstellungen können vorgenommen werden:

Ø Bezeichnung

An dieser Stelle erfolgt die Eingabe der Bezeichnung, welche in weiterer Folge im Cockpit angezeigt werden soll.

Ø Link

In diesem Feld wird der Link der Internetseite eingegeben, die aufgerufen werden soll. Hierbei ist nicht unbedingt notwendig den gesamten Link einzutragen, sondern es genügt der Name und die Erweiterung (.com,.de,.at, etc.), der Rest wird vom Programm selbstständig ergänzt.

Ø Darstellung

An dieser Stelle wird definiert, wie der Eintrag im Cockpit dargestellt werden soll. Hierfür stehen folgende Optionen zur Verfügung:

ü 0 - Text  
Im Cockpit wird ein Link zu der gewünschten Internetseite dargestellt.

ü 1 - Website  
Die Internetseite wird direkt im Cockpit dargestellt. Hierfür ist es notwendig die Seite in einem eigenen Bereich darzustellen, d.h. sie wird mit einer eigenen Überschrift versehen.

Achtung

Bei der Eingabe einer URL ist sowohl HTTPS als auch HTTP möglich, sofern die Option "Unsicheren Browser zulassen" (siehe "Einstellungen…", Register "Admin") aktiviert wurde. Die Übertragung über HTTP erfolgt jedoch unverschlüsselt und ist daher nicht sicher, da sensible Daten (z.B. Zugangsdaten oder personenbezogene Informationen) von Dritten eingesehen oder manipuliert werden können. Wir empfehlen daher ausdrücklich, ausschließlich HTTPS-URLs zu verwenden!
