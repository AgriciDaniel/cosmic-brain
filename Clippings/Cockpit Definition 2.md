### Cockpit Definition - Menüpunkt

Mit dem Element "Menüpunkt" können Menüpunkte aus allen WinLine Applikationen (ausgenommen WinLine ADMIN) im Cockpit integriert werden. Hiermit kann erreicht werden, dass vom Cockpit aus direkt das gewünschte Programm in der entsprechenden Applikation aufgerufen wird.

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_318.png)

Die folgenden Einstellungen können vorgenommen werden:

Ø Bezeichnung

An dieser Stelle erfolgt die Eingabe der Bezeichnung, welche in weiterer Folge im Cockpit angezeigt werden soll.

Hinweis

Durch Auswahl einer Liste wird der Name automatisch vorbelegt.

Ø Suchbegriff

Durch Eingabe und Bestätigung eines Suchbegriffs wird in allen zur Verfügung stehenden Menüpunkten gesucht und die Suchergebnisbaumstruktur entsprechend aufgebaut.

Ø Menüpunkt-Auswahl

An dieser Stelle erfolgt über eine Baumstruktur die Auswahl, welcher Menüpunkt im Cockpit zur Verfügung stehen soll.

Hinweis

Im Standard sind alle Menüpunkte aus allen WinLine Applikationen ersichtlich, die über das Cockpit angesprochen werden können. Dieses sind im Prinzip alle Programme mit Ausnahme des Programms WinLine ADMIN.

Ø Vorlage

Wenn es sich bei dem Menüpunkt um einen Programmpunkt handelt, in welchem mit individuellen Vorlagen gearbeitet werden kann (z.B. Sachkontenstamm, Personenkontenstamm, Artikelstamm, etc.), dann kann an dieser Stelle eine Vorlage zugewiesen werden.

Eine Ausnahme bildet der Menüpunkt "Kassen-Eingang/Ausgang". Über die Vorlagen-Zuordnung kann definiert werden, welches Register ("Kasseneingang" oder "Kassenausgang") geöffnet werden soll.

Hinweis

Die Anlage von Vorlagen findet im Programm "Vorlagen Anlage" (WinLine START - Vorlagen) statt.

Ø WinLine FORM

Handelt es sich bei dem gewählten Menüpunkt um das "DataCenter" des WinLine FORM, so kann an dieser Stelle die FORM gewählt werden, welche direkt geöffnet werden soll. Bei Auswahl von "00000 - <KEINE>" wird das DataCenter ohne gewählte FORM geöffnet.

Ø Darstellung

Für die Menüpunkte "Arbeitszeitauswertungen" und "Zeiterfassung" (WinLine SMART TIME) kann an dieser Stelle definiert werden in welcher Applikation das Fenster aufgehen soll (WinLine START oder WinLine INFO).
