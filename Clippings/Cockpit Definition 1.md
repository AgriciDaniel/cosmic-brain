### Cockpit Definition - Überschrift

Mit dem Element "Überschrift" kann ein Ordner (auch "Widget" genannt) für einzelne Einträge gebildet werden. Dieses dient zur Zusammenfassung von mehreren Einträgen, z.B. "Meine täglichen Auswertungen".

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_317.png)

Die folgenden Felder können bearbeitet werden:

Ø Bezeichnung

Hier wird die Bezeichnung bzw. die Überschrift eingetragen.

Ø Spalte

Im Cockpit sind grundsätzlich 3 Spalten vorhanden. Aus der Auswahlbox kann gewählt werden, in welcher Spalte dieser neue Eintrag dargestellt werden soll.

Ø Darstellung

An dieser Stelle kann definiert werden, ob der Ordner, welcher durch die Überschrift bildet wird, geöffnet oder geschlossen dargestellt werden soll.
