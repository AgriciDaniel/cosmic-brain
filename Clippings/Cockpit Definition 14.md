### Cockpit Definition - SCORE

Mit Hilfe des Elements "SCORE" können bezugnehmende Widgets eingebunden werden.

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_342.png)

Ø Bezeichnung

An dieser Stelle erfolgt die Eingabe des Namens, welcher in weiterer Folge als Überschrift für das Widget genutzt wird.

Ø Auswahl

In diesem Bereich kann definiert werden, was in dem Widget dargestellt werden soll.

ü 0 - Score Rangliste  
Dieses Widget zeigt Informationen über eine Score Rangliste an.

ü 1 - Score Erfolge  
Das Erfolge Widget zeigt einen beliebigen einmaligen Erfolg an.

ü 2 - Score wiederholbare Erfolge  
Das wiederholbare Erfolge Widget zeigt einen beliebigen wiederholbaren Erfolg an.

ü 3 - Score Teilnehmer  
Das Score Teilnehmer Widget zeigt Informationen über den eingeloggten User an.

ü 4 - Score Geschäftsziel  
Gibt Informationen eines Score-Geschäftziels wieder.

Beispiel

Es wurde ein SCORE Widget des Typs "0 - Score Rangliste" implementiert. Über die Einstellungen des Widgets wurden zusätzlich noch die Überschrift, die Ranganzeige, die Rangliste als solches und die Farbe angepasst:
