### Cockpit Definition - Datenquellen

Mit Hilfe des Elements "Datenquellen" können erzeugte Datenquellen (Snapshots, Views oder MasterViews) in das Cockpit eingebaut werden.

Hierbei kann das Erscheinungsbild (Diagramm, Tabelle, Tag Cloud, etc.) individuell vorgegeben werden.

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_346.png)

Die folgenden Einstellungen können vorgenommen werden:

Ø Bezeichnung

An dieser Stelle erfolgt die Eingabe der Bezeichnung, welche in weiterer Folge im Cockpit angezeigt werden soll.

Ø Datenquelle auswählen

Durch Anwahl dieses Buttons wird der "Datenquellen - Matchcode" geöffnet. In diesem werden alle Datenquellen (auf welche der aktuelle Benutzer ein Zugriffrecht besitzt) angezeigt.

Ø Datenquelle

In den einzelnen Felder ("Datenquelle" bis "Selektion 4") werden die Informationen zu der ausgewählten Datenquelle angezeigt.

Ø Ausgabe

An dieser Stelle wird definiert, wie die Datenquelle grundsätzlich im Cockpit dargestellt werden soll. Hierfür stehen folgende Optionen zur Verfügung:

ü 00 - Kachel

ü 01 - Diagramm

ü 02 - Tabelle

ü 03 - Geo Map

ü 04 - Tag Cloud

ü 05 - Kanban

ü 06 - Olap

ü 07 - Datentabelle

ü 08 - Fortschrittsanzeige

ü 09 - Kalender

ü 10 - Detail-Diagramm

Hinweis

Das endgültige Erscheinungsbild wird im Anschluss über das Cockpit definiert. Nähere Information hierzu entnehmen Sie bitte dem Kapitel [Zusätzliche Funktionen im Cockpit](https://www.mesonic.com/cwlhelp/WordDocuments/zus%C3%A4tzlichefunktionenimcockpit.htm).
