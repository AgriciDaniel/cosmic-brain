Die WinLine Cockpits der Applikationen [WinLine START](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitwinlinestart.htm) bzw. [WinLine INFO](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitwinlineinfo.htm) bilden den Startpunkt nach dem Programmeinstieg.

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_229.png)

Diese Cockpits können pro WinLine Benutzer individuell gestaltet werden (siehe auch [Zusätzliche Funktionen im Cockpit](https://www.mesonic.com/cwlhelp/WordDocuments/zus%C3%A4tzlichefunktionenimcockpit.htm)) und dabei u.a. folgende Elemente beinhalten:

ü [Überschrift](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinition%C3%BCberschrift.htm)  
Mit Hilfe einer Überschrift kann ein Ordner / Container für einzelne Einträge gebildet werden, wobei man hier von einem sogenannten "Widget" spricht. Dieses dient zur Zusammenfassung von mehreren Einträgen, z.B. "Meine täglichen Auswertungen".

ü [Menüpunkt](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionmen%C3%BCpunkt.htm)  
Mit dem Element "Menüpunkt" können Menüpunkte aus allen WinLine Applikationen (ausgenommen WinLine ADMIN) im Cockpit integriert werden. Hiermit kann erreicht werden, dass vom Cockpit aus direkt das gewünschte Programm in der entsprechenden Applikation aufgerufen wird.

ü [Aktuelle Objekte](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionaktuelleobjekte.htm)  
Mit dem Element "Aktuelle Objekte" können die zuletzt in der WinLine verwendeten Objekte in Form einer Kachel angezeigt werden. Über die Anwahl solch einer Kachel kann eine Aktion für das jeweilige Objekt ausgeführt werden.

ü [Liste](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionliste.htm)  
Mit dem Element "Liste" können Auswertungen abgerufen werden, welche im Programm WinLine LIST (WinLine LIST - Liste - Assistent) erstellt wurden.

ü [Report](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionreport.htm)  
Mit dem Element "Report" können vom Programm vorbereitete Auswertungen abgerufen werden.

ü [OIF](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionoif.htm)  
Das Element "OIF" (Objektorientiertes Info Formular) ermöglicht es allgemeine oder objektabhängige Information im Cockpit anzeigen zu lassen.

ü [MesoCalc](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionmesocalc.htm)  
Mit dem Element "MesoCalc" kann eine Grafik, welche im MesoCalc (WinLine INFO - Info) definiert wurde, angezeigt werden.

ü [WinCalc](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionwincalc.htm)  
Das WinCalc stellt die alternative zu Microsoft Excel in WinLine dar und bietet neben einer Tabellenkalkulation, Formeln und Funktionen, einem Berechtigungssystem, sowie Ex- und Importfunktionen, auch den Datenzugriff auf fast alle Datenquellen-Widgets des Cockpits.

ü [Makro](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionmakro.htm)  
Mit dem Element "Makro" kann ein Makro gestartet werden, welches innerhalb der WinLine aufgenommen oder programmiert wurde. Ein Makro dient dazu, gewisse Arbeitsabläufe zu automatisieren.

ü [CRM-Eintrag](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitioncrmeintrag.htm)  
Mit dem Element "CRM-Eintrag" kann direkt aus dem Cockpit heraus ein Workflowstartpunkt oder ein Aktionsschritt gestartet werden.

ü [Applikation](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionapplikation.htm)  
Mit dem Element "Applikation" kann direkt aus dem Cockpit heraus ein beliebiges anderes - auf dem PC installiertes - Programm (z.B. ein Textverarbeitungsprogramm oder die Bankensoftware) gestartet werden.

ü [Bild](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionbild.htm)  
Mit dem Element "Bild" können Bilder bzw. Grafiken im Cockpit angezeigt werden.

ü [Internetlink](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitioninternetlink.htm)  
Mit dem Element "Internetlink" kann ein Verweis auf eine Internetseite erstellt werden. Dadurch kann mit einem einfachen Klick die gewünschte Seite im Browser aufgerufen werden.

ü [HTML](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionhtml.htm)  
Das Element "HTML" ermöglicht es selbst definierte HTML-Elemente in das Cockpit zu integrieren.

ü [Zeiterfassung](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitionzeiterfassung.htm)  
In dem Element "Zeiterfassung" wird die eigene Zeiterfassung aus dem Modul WinLine SMART TIME in Form eines Widgets dargestellt.

ü [Datenquellen](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitdefinitiondatenquellen.htm)  
Mit Hilfe des Elements "Datenquellen" können erzeugte Datenquelle in das Cockpit eingebaut werden, wobei das Erscheinungsbild (Diagramm, Tabelle, Tag Cloud, etc.) individuell vorgegeben werden kann.

ü [Quick-Info-Leiste](https://www.mesonic.com/cwlhelp/WordDocuments/zus%C3%A4tzlichefunktionenimcockpit.htm)  
In der Quick-Info, welche sich im linken Bereich des Cockpits befindet, wird auf ungelesene Objekte aus den Bereichen "Neuigkeiten", "Share", "MesoMail" hingewiesen, wobei per Anwahl das entsprechende Programm gestartet wird. Des Weiteren kann das WinLine Score geöffnet und ein Cockpitwechsel initiiert werden.

Die WinLine Cockpits stehen in den Applikationen [WinLine START](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitwinlinestart.htm) und [WinLine INFO](https://www.mesonic.com/cwlhelp/WordDocuments/cockpitwinlineinfo.htm) zur Verfügung, wobei unterschiedliche Funktionen bereitstehen. Diese werden in den nachfolgenden Kapiteln detailliert erläutert.

Hinweis

Bei einer Auflösung über 1920x1080p (HD+) und einer eingestellten Textvergrößerung von Windows werden die Kacheln eines Cockpits skaliert und somit, je nach Einstellung, größer dargestellt.
