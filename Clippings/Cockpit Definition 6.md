### Cockpit Definition - MesoCalc

Mit dem Element "MesoCalc" kann eine Grafik, welche im MesoCalc (WinLine INFO - Info) definiert wurde, angezeigt werden.

![](https://www.mesonic.com/cwlhelp/ImagesExt/image856_332.png)

Die folgenden Einstellungen können vorgenommen werden:

Ø Bezeichnung

An dieser Stelle erfolgt die Eingabe der Bezeichnung, welche in weiterer Folge im Cockpit angezeigt werden soll.

Ø Auswertung

Aus der Auswahlliste kann eine MesoCalc-Auswertung ausgewählt werden, welche im Cockpit angezeigt werden soll. Damit die Auswertung dargestellt werden kann, muss im MesoCalc selbst die Definition der Grafik hinterlegt worden sein.

Hinweis

MesoCalc-Grafiken werden im Cockpit in einem eigenen Bereich dargestellt, d.h. diese werden mit einer eigenen Überschrift versehen.
