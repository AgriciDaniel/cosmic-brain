# Fluent 2 Content Design

Words are **design material** alongside iconography and illustration. "What you say, when you say it, and how are all important factors."

## Designing Content — Three Questions

1. **Who is your audience?**
2. **What do they want to accomplish?**
3. **How might they feel?**

## Writing — Three Core Principles

- **Keep it simple** — plain language, short sentences, fragments OK for scannability
- **Get to the point fast** — make choices obvious, give just enough to decide
- **Talk like a person** — informal, conversational, one-on-one

## Best Practices

| Rule | Note |
|------|------|
| **Present tense** | Easier than past/future for most contexts |
| **Active voice** | Direct, people-focused. Passive only when avoiding org reference |
| **Capitalization** | Sentence-case on Windows/Android/Web; title-case on iOS/macOS |
| **No jargon** | Translate to broad-audience language |
| **Use headings** | They're the content outline that decides engagement |
| **Second person** | "you, your, yours" |

## Punctuation

- **Question marks**: always for questions
- **Periods**: only after complete sentences
- **Exclamation points**: rare, celebratory only
- **Minimize punctuation** in UI elements (headers, buttons, lists)

## Accessibility & Global Readiness

- **Link text**: short, descriptive — never "Click here"
- **No directional terms**: avoid "above," "below," "right," "left" (fail in screen readers / RTL / reflow)
- **Alt text** for illustrative visuals
- **Logical organization** via headings/tables/lists
