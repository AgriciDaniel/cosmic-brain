# Fluent 2 Onboarding

Not a singular event. "Different teaching points in a user's journey [offered] when people are ready to take it in."

## Five Principles

| Principle | Meaning |
|-----------|---------|
| **Relevant** | Surface within context of related tasks (better retention) |
| **Non-distracting** | Never a barrier to the primary goal |
| **Optional** | Exit + return possible — no forced completion |
| **Benefit-focused** | Upfront clarity about personal benefit (users skip when unclear) |
| **Coherent** | Standard Fluent components for predictability |

## Five Goals & Their Patterns

| Goal | Patterns | Notes |
|------|----------|-------|
| **Welcome** | One-time screen, banner, or modal | Reassure; emphasize benefits; brief, scannable |
| **Orient** | Empty states, teaching popovers | Direct attention to specific UI options in context |
| **Notify** | Banners, empty states, popovers, toasts | Explain new/changed functionality |
| **Explain** | Embedded hints in UI (esp. empty states) | Concise + clear CTA |
| **Take action** | First-run flows, carousel wizards, drawer multi-step | Guide preliminary setup |

## Content Guidelines

- **Action-oriented language** — strong verbs; CTAs complete *"I want to…"*
- **Inclusive phrasing** — "Need help?" not "Stuck?"
- **Set time expectations** — "This takes 2–3 minutes" for setup flows
