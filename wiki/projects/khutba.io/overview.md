# khutba.io — Product Overview

## Project Metadata

- GitHub: https://github.com/manazoid4/khutba-io
- Local PC location: `C:\Users\manaz\khutba-io`
- Live marketing/demo: https://khutba-io.vercel.app

## Definition

Screen-first Live Khutbah Platform for masjids. The category line is “the live language layer for the masjid”; the long-term expansion is a Mosque Communication OS.

Launch: Birmingham, UK. Expand nationally, then globally.

## Core Product

| Layer | What |
|---|---|
| Input | Live mic audio from speaker/pulpit |
| Engine | Speech-to-text + real-time translation |
| Output | Auto-scrolling multilingual text on display screens |
| Languages | Arabic, English, Urdu, Somali, Bengali (expandable) |

## Current Product Reality

- Marketing, pricing and account-free scripted demo are live on Vercel.
- Local React admin/display pairing and explicit live session flow work.
- Production STT/translation, auth, persistence, billing, verified prayer times and hosted realtime infrastructure remain release gates.
- Do not claim unlimited usage, GDPR compliance, UK data residency or religious verification until proven and documented.

## Product Tiers

| Tier | Product | Role |
|---|---|---|
| Core | £79/mo or £790/yr | One-site Friday workflow, up to three text languages |
| Pro | £149/mo or £1,490/yr | Multiple outputs, glossary, archive/livestream expansion |
| Network | From £399/mo or £3,990/yr | Three sites, roles and central control |
| Funnel | Four-Friday pilot | Equipment, languages and volunteer workflow proven before annual close |

## Strategy

Translation is the hero acquisition feature. Friday Readiness and the mosque glossary create trust. Daily prayer/standby/announcement modes are the retention layer. Multi-site control, embeds and archive create expansion. The first ICP is a visible medium-to-large multilingual UK mosque with an existing mixer and screen.

## Why It Exists

- Non-Arabic speakers (Urdu, Somali, Bengali, English) miss meaning of khutba
- Existing mosque-specific competitors leave room for a simpler, more dependable UK screen workflow
- Masjids rely on volunteers translating manually — unreliable
- High community trust = word-of-mouth growth within Muslim networks
