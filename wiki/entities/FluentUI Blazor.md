# FluentUI Blazor

A Microsoft component library for Blazor that implements the Fluent Design System. Provides accessible, design-system-consistent UI components for .NET Blazor applications.

## Key Facts

- **Maintainer**: Microsoft
- **Version tracked**: v5.0.0-RC.3 (as of 2026-05-23)
- **Platform**: Blazor (ASP.NET Core)
- **Design system**: Microsoft Fluent Design
- **Docs**: https://fluentui-blazor-v5.azurewebsites.net/

## Notes

Components follow WAI-ARIA patterns. Accessibility is a first-class concern: components that don't receive focus (like badges) expose their content through parent labeling conventions.
