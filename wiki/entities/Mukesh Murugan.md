# Mukesh Murugan

Software Engineer and technical author/educator, publishing at codewithmukesh.com. Author of the ".NET Web API Zero to Hero" course (147 lessons — `dotnet new` through `docker push`: REST, EF Core 10, auth, caching, Clean Architecture, observability) and a broader .NET interview-prep series (300+ questions across C#, EF Core, ASP.NET Core, system design).

## Content Style

Interview-prep articles follow a consistent format: a real scenario framed as a question, a model answer that states the mechanism + trade-off + default recommendation, an explicitly named "red flag answer" that signals shallow/tutorial-only knowledge, and (for senior-level questions) an interviewer follow-up. Content is scoped tightly to current framework versions (EF Core 10 / .NET 10 at time of writing) and explicitly calls out where behavior diverges from legacy versions (e.g., EF Core vs. legacy Entity Framework 6).
