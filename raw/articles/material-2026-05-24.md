# Material - Fluent 2 Design System

## Overview

Material describes the texture of a surface. Fluent supports four materials: solid, mica, acrylic, and smoke.

## Material Types

Fluent offers solid, occluding, and transparent material types. "Occluding materials, like Acrylic and Mica, appear widely on Windows as base layers" beneath interactive UI components. Transparent materials, like smoke, are used less frequently to highlight immersive surfaces.

## Solid

Most common material type. Opaque material using color and varying elevation to highlight UI regions and interactions. Mode aware (light + dark).

## Acrylic

Semi-transparent material replicating frosted glass. Use "for transient, light-dismiss surfaces such as popovers and menus." Mode aware.

## Mica

Opaque material subtly tinted with a user's desktop background color on an active window. "If the window is inactive, mica takes on a neutral color." Built-in Windows feature indicating focus. Mode aware.

## Smoke

Emphasizes an important surface by dimming the interface beneath. "Signals blocking interactions below a modal component, like a dialog." Not mode aware — "always translucent black."
