Button

 

Das Element "Button" wird nur bei FORMs benötigt, die in der MesoCloud gespeichert werden. Damit kann dann das FORM im Webbrowser gespeichert / abgeschickt werden. Wenn in einer MesoCloud-FORM kein Button eingebaut wird, wird dieser vom Programm automatisch eingefügt.

 

Die Einstellungen (Button) sind unterteilt in den Button "KOPIEREN" und "LÖSCHEN", "Optionen" und "MesoAI".

 

Optionen

Ø  Beschriftung

Hier kann die Bezeichnung des Buttons eingetragen werden. Vorgeschlagen wird "Button"

 

Ø  nur Lesen

Im DataCenter können keine Erfassungen vorgenommen werden, wenn diese Checkbox aktiviert ist.

 

Ø  MesoIcon

Es kann aus einer diversen Auswahl ein Icon links im Button abgebildet werden.

 

Ø  Höhe

Voreingestellt ist die Höhe mit 0 und kann geändert werden

 

Ø  Breite

Voreingestellt ist die Breite mit 0 und kann geändert werden.

 

Ø  Design

Es kann zwischen verschiedenen Designfarben gewählt werden.
