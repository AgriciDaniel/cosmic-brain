Betrieb

 

Ø  Name

Eingabe des Firmennamens bzw. der Kostenstelle

 

Ø  Straße, Straße 2

Hier kann die Adresse der Firma eingetragen werden.

 

Ø  Land

Aus der Auswahllistbox kann der Landescode des Staates ausgesucht werden, in dem der Betrieb seinen Standort hat. Diese Information wird auch für die elektronische Übermittlung an die ELDA benötigt.

 

Ø  PLZ1, PLZ2, Ort

Eingabe der restlichen Adresse, die auch bei wichtigen Ausdrucken andruckbar ist (z.B. Lohnzettel - L16, Beitragsnachweisung, etc.).

 

Ø  Telefon, Fax

Eingabe der Telefon- bzw. Faxnummer, die ebenfalls für die elektronische Übermittlung benötigt wird.

 

Ø  E-Mail:

In diesem Feld kann die e-Mail-Anschrift hinterlegt werden.

 

Ø  Inaktiv

Durch Aktivieren der Checkbox wird der Betriebsstamm auf Inaktiv gesetzt. Dieser Betrieb darf daher in keiner Abrechnung bzw. auch in keinem AN-Stamm mehr vorkommen.

Inaktive Betriebsstämme werden auch im Betriebsstamm-Matchcode nicht angezeigt und können nur über den Reorg gelöscht werden.

 

Ø  Hauptbetrieb

Ist diese Checkbox aktiv, wird der aktuelle Betriebsstamm als Hauptbetrieb gekennzeichnet - alle weiteren Betriebe haben dann den Status eine Zweigstelle bzw. einer Kostenstelle. Die erfassten Daten werden auch in das Register "Herstellerstamm" übergeben und können dort ggf. überarbeitet werden.

 

Ø  BUAK

Aus der Auswahllistbox kann ausgewählt werden, ob Mitarbeiter dieses Betriebs der BUAK unterliegen. Zur Auswahl stehen:

 

ü  Nein

Ist auszuwählen, wenn kein Mitarbeiter der BUAK unterliegt.

ü  Direktzahlung
Ist auszuwählen, wenn Mitarbeiter der BUAK unterliegen und es kein eigenes Treuhandkonto gibt.

ü  Ja

Ist auszuwählen, wenn Mitarbeiter der BUAK unterliegen und es ein Treuhandkonto gibt.

 

Finanzbuchhaltung

Ø  Finanzbuchhaltung - Mandant

Hier kann eingestellt werden, in welchem Mandanten die Buchungen, die im Zuge der Buchungsübergabe erzeugt werden, und die Clearing-Daten, die im Zuge der Auszahlung erzeugt werden, gespeichert werden sollen.

 

Aus der Auswahllistbox kann der gewünschte Mandant gewählt werden. Sollen die Buchungen im gleichen Mandanten gespeichert werden, muss auch die gleiche Mandantennummer eingetragen werden.

 

Ø  Hilfskostenstelle für Sonderzahlungen

Hier kann eine Hilfskostenstelle eingetragen werden, auf die Sonderzahlungen verbucht werden sollen. Wird bei der Erfassung eine Lohnart angesprochen, bei der das SV- oder Lohnsteuerkennzeichen aus S-Sonderzahlung steht, dann wird nicht die Stammkostenstelle aus dem AN-Stamm, sondern die Hilfskostenstelle aus den Betriebsdaten vorgeschlagen. Bleibt das Feld in den Betriebsdaten leer, dann wird auch bei Sonderzahlungen die Stammkostenstelle aus dem AN-Stamm übernommen.

 

Durch Drücken der F9-Taste kann nach allen angelegten Kostenstellen gesucht werden, wobei im Matchcode nur die Hilfskostenstellen vorgeschlagen werden. Wird eine Kostenstelle angegeben, die im Datenstand nicht angelegt ist, wird eine entsprechende Meldung ausgegeben, die Kostenstelle kann trotzdem verwendet werden.

 

Ø  Fehlerkostenstelle

Hier kann eine Fehlerkostenstelle eingetragen werden, auf die Werte gebucht werden, die sonst keiner Kostenstelle zugeordnet werden können. Dies ist z.B. dann der Fall, wenn die Profit Center Aufteilung auf Basis von Erfassungszeilen durchgeführt wird, bei einigen Zeilen aber keine Kostenstelle eingetragen wird. Die Fehlerkostenstelle wird auch nur dann verwendet, wenn die KORE-Buchungen über die FIBU-Buchungen erfolgen (siehe auch Applikations-Parameter / LOHN-Parameter im WinLine START).

 

Durch Drücken der F9-Taste kann nach allen angelegten Kostenstellen gesucht werden, wobei im Matchcode nur die Hilfskostenstellen vorgeschlagen werden. Wird eine Kostenstelle angegeben, die im Datenstand nicht angelegt ist, wird eine entsprechende Meldung ausgegeben, die Kostenstelle kann trotzdem verwendet werden.

 

Diese Information kann pro Betriebsstamm hinterlegt werden.

 

Standard Beschäftigungszeiten

Ø  Tage pro Woche

Hier können die Standard Beschäftigungstage pro Woche hinterlegt werden. Diese Angabe wird bei diversen SV-Meldungen als Vorbelegung herangezogen.

 

Ø  Stunden pro Woche

Hier können die Standard Beschäftigungsstunden pro Woche hinterlegt werden. Diese Angabe wird bei diversen SV-Meldungen als Vorbelegung herangezogen.

 

Urlaubsanspruch

Ø  Per

Hier kann definiert werden, ob der Urlaubsanspruch für diesen Betrieb Standardmäßig auf Basis des Arbeitsjahres (Eintrittsdatum) oder auf Basis des Kalenderjahres berechnet wird. Abhängig davon wird bei der Anlage von neuen AN der "Stichtag für Urlaubsanspruch" vorbelegt.

 

EFZG-Anspruch

Ø  Per

Hier kann definiert werden, ob der EFZG Anspruch für diesen Betrieb Standardmäßig auf Basis des Arbeitsjahres (Eintrittsdatum) oder auf Basis des Kalenderjahres berechnet wird. Abhängig davon wird im Menüpunkt EFZG Berechnung eine entsprechende Berechnung vorgeschlagen.
