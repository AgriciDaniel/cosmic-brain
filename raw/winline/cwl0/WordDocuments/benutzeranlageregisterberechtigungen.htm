Benutzeranlage - Register "Berechtigungen"

 

Die WinLine Berechtigungsvergabe kennt mehrere Möglichkeiten, um dem Benutzer den Zugriff auf bestimmte Mandanten oder Programmpunkte zu ermöglichen oder auszuschließen.

Hinweis

Die Stammdaten des aktuellen Benutzers werden im Register Stammdaten hinterlegt.

 

 

Die Berechtigungsvergabe ist in folgende Register untergliedert, welche in den nachfolgenden Kapiteln detailliert erläutert werden:

 

ü  Register "Benutzer -> Mandant"
Im Register "Benutzer -> Mandant" kann definiert werden, auf welche Mandanten und Applikationen ein Benutzer zugreifen darf.

 

ü  Register "Mandant -> Benutzer"
Im Register "Mandant -> Benutzer" kann eingestellt werden, welcher Mandant von welchen Benutzer bearbeitet werden darf.

 

ü  Register "Administrator"
In dem Register "Administrator" können normalen Benutzern Administratorenrechte zugewiesen werden.

 

ü  Register "Benutzergruppen"
Im Register "Benutzergruppen" kann einem Benutzer eine oder mehreren Benutzergruppen zugeordnet werden.

 

ü  Register "Downloads"
Im Register "Downloads" kann festgelegt werden, welche Bereiche für den jeweiligen Benutzer in der "Download Liste" angezeigt werden sollen.

 

Buttons

 

Ø  aktuelle Tabelleninhalte speichern

Durch Anwahl des Buttons "aktuelle Tabelleninhalte Speichern" bzw. der Taste F5 werden die hinterlegten Berechtigungen gespeichert.

 

Ø  Ende

Durch Anklicken des "Ende"-Buttons bzw. durch Drücken der "ESC"-Taste wird das Fenster geschlossen und alle nicht gespeicherten Änderungen verworfen.

 

Ø  Löschen

Der Button steht nur im Register Stammdaten zur Verfügung.

 

Ø  Berechtigungen eines anderen Benutzers übernehmen

Der Button steht nur im Register Stammdaten zur Verfügung.

 

Ø  alle Einstellungen eines anderen Benutzers übernehmen

Der Button steht nur im Register Stammdaten zur Verfügung.

 

Ø  Statistik komprimieren

Der Button steht nur im Register Stammdaten zur Verfügung.

 

Ø  Bildersuche

Der Button steht nur im Register Stammdaten zur Verfügung.

 

Ø  2-Faktor Authentifizierung

Der Button steht nur im Register Stammdaten zur Verfügung.
