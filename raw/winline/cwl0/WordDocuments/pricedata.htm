PriceData

 

Funktion

Diese Funktion dient dazu, die Parameter, welche für die Preisfindung verwendet werden, zu belegen. Es können das Konto, die Preisliste, die Rabattleisten, das Datum, die Kundengruppe und die Option "immer den billigsten Preis verwenden" übersteuert werden. Dabei können folgende Werte (pos) belegt werden:

 

ü  pcAccount                     => Preisfindungskonto

ü  pcPricelist                     => Preisliste

ü  pcAccountgroup             => Kundengruppe

ü  pcDiscountlist1              => Rabattleiste1

ü  pcDiscountlist2              => Rabattleiste2

ü  pcBestprice                   => Bestpreis-Flag

ü  pcDate                          => Datum

Syntax

PriceData pos, Value

 

Beispiele

PriceData pcAccount, "230A001"

Es wird fix das Konto 230A001 verwendet.

 

PriceData pcAccount, Value (50,169)

Es wird das Händlerkonto verwendet.

 

PriceData pcPricelist, 1

Es wird die Preisliste 1 verwendet.

 

Achtung

Die Änderungen wirken solange, bis entweder ein Parameter manuell im Programm geändert wird (z.B. die Preisliste im Reiter Zusatz neu eingegeben wird) oder eine andere Formel aufgerufen wird, die diese Parameter setzt.

Hinweis

Diese Funktion wird in der Belegformel nicht unterstützt.
