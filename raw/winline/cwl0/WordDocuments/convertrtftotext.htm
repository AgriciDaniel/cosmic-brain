ConvertRTFToText

 

Mit der Funktion "ConvertRTFToText" kann eine Variable, die einen RTF-Text enthält (z.B. Artikelnotiz oder dergleichen) in einen "normalen" Text umgewandelt werden. Damit können dann z.B. auch unterschiedliche Notiz-Informationen zu einer Variable "zusammengefasst" werden.

 

Ø  Syntax

ResultValue = ConvertRTFToText (Variable)

 

Beispiel

ResultValue = ConvertRTFToText (Value (21,80)) & chr(13) & chr(10) &  Value (21,73)

 

In diesem Beispiel werden die Variablen "Notiz 1" und "Langtext 1" aus dem Artikelstamm zusammengefügt, wobei zwischen den beiden Texten ein Zeilenumbruch eingefügt wird.

Achtung

Wenn das Ergebnis der Formel direkt ausgeben wird, dann interpretiert die VB-Formel das Ergebnis als "%s"-Inhalt und gibt es entsprechend aus. Hierbei handelt es sich immer um eine einzeilige Ausgabe!

Grundsätzlich gibt es für die mehrzeilige Ausgabe in einem %s-Elementen die Option "Multiline" (samt Eingabe der "Breite"), welches allerdings per direkter Formelausgabe nicht mitgeben werden kann. D.h. für eine mehrzeilige Ausgabe muss das Ergebnis der Formel in eine SQL-Variable (ab 500/100) gestellt werden. Per Element "Text Variable" (%s) kann der Inhalt der SQL-Variable anschließend formatiert ausgeben lassen.
