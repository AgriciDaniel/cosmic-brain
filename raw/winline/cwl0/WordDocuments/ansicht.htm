WinLine BI > WinCalc > Ansicht

Ansicht

 

Im Bereich "Ansicht" kann u.a. der Zoomfaktor bestimmt werden.

 

 

Ø  Anzahl / Summe / Durschnitt

An dieser Stelle werden Summen-Informationen zu den aktuell markierten Zellen ausgegeben.

 

Ø  Einstellungen

Über die "Einstellungen" kann die Anzahl der Zeilen für die folgenden Übergaben definiert werden:

 

ü  Funktion "Ausgabe WinCalc" in "List - Assistent" und "List - Ausgabe"

ü  Funktion "Ausgabe WinCalc" in WinLine Tabellen

ü  Funktion "WinCalc" in der View 360

ü  Import von Excel-Dateien

 

Ø  Layout

Mit Hilfe dieser Buttons kann das Layout des CalcSheets gewählt werden.

 

Ø  Zoom

An dieser Stelle kann der Zoom des CalcSheets individuell hinterlegt werden.
