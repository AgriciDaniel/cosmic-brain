1  Autobeleg starten

 

… können zuvor definierte Autobelege-Termine (auch "Aktionsplan" genannt) durchgeführt bzw. gelöscht werden.

Hinweis

Bei der Durchführung werden Quellbelege auf die Zielkonten dupliziert. Bei dem Löschen können zuvor duplizierte Belege wieder gelöscht werden.

 

 

Das Fenster in die folgenden Register unterteilt, welche in den nachfolgenden Kapiteln beschrieben werden:

 

ü  Register "Starten"
In dem Register "Starten" können die Grundeinstellungen für das Durchführen einer Autobeleg-Duplizierung hinterlegt werden.

 

ü  Register "Vorschau"
In dem Register "Vorschau" kann eine manuelle Selektion erfolgen, welche Belege erzeugt werden sollen.

 

ü  Register "Löschen"
Mit Hilfe des Registers "Löschen" können Belege, welche über diesen Programmbereich erzeugt wurden, anhand der Vorgangsnummer, wieder gelöscht werden

 

Buttons

 

Ø  Starten (nicht im Register "Löschen")

Durch Anwahl des Buttons "Starten" bzw. der Taste F5 werden die Belege, entsprechend der vorgenommenen manuellen Auswahl, auf die Zielkonten dupliziert. Wurde das Register "Vorschau" im Vorfeld nicht angewählt, so erfolgt die Duplizierung allein aufgrund der Einstellungen des Registers "Starten".

Hinweis

Nach dem Start des Autobelegs sind die Termine / Aktionen im gewählten Zeitraum zu Belegen umgewandelt worden. Hierbei werden zunächst immer "nicht gerechnet / gedruckte" Belege erstellt, welche im Anschluss manuell oder über das Programm Belegdruck ausgegeben werden müssen.

 

Ø  Ende

Durch Anwahl des Buttons "Ende" bzw. der Taste ESC wird das Fenster geschlossen.

 

Ø  Löschen (nur im Register "Löschen")

Nach der Auswahl einer Vorgangsnummer im Register "Löschen" kann mit Hilfe dieses Buttons das Löschen durchgeführt werden.

 

Ø  Vorschau (nicht im Register "Löschen")

Mit Hilfe des Buttons "Vorschau" wird eine Liste über alle Belege, welche nun erzeugt werden würden, am Bildschirm ausgegeben.
