Variablen für das Steuern der Optionen (Belegerfassung)

 

In der Belegerfassung können diverse Einstellungen im Register "Optionen" individuell hinterlegt werden. Mit Hilfe der folgenden Variablen und einer "Belegkopfformel (Laden)" können die Optionen in Abhängigkeit der Belegart gesetzt werden.

 

Achtung

Wenn eine Option mit Hilfe eine Formel verändert wurde, so bleibt die Einstellung auch beim Beenden der Belegerfassung für den Benutzer erhalten.
