WinLine Funktionen

 

Das WinCalc stellt eine Reihe von Funktionen zur Verfügung, welche es ermöglichen, auf die Daten der WinLine zuzugreifen. Eine detaillierte Beschreibung kann den nachfolgenden Kapiteln entnommen werden.

Hinweis

Eine Aktualisierung der WinLine Funktion findet immer statt, wenn sich eine Zelle, auf welche Bezug genommen wird, verändert. Zusätzlich kann durch Anwahl des Button Funktionen aktualisieren eine Aktualisierung aller WinLine Funktionen ausgelöst werden.

Achtung

WinLine Funktionen ermöglichen nicht das direkte weiterrechnen innerhalb der Funktion. D.h. soll der Wert eine WinLine Funktion in eine Berechnung einfließen, so muss die Berechnung auf das Ergebnis der WinLine Funktion zugreifen. Auch wird das Einfügen von WinLine Funktion in Standard Funktionen (z.B. =SUM) nicht unterstützt.

Beispiel

Der Saldo von Erlöskonten wird aus buchhalterischer Sicht negativ dargestellt und so bei Nutzung der SUMKTO-Funktion auch im WinCalc angezeigt.

 

 

Um den Wert positiv darzustellen darf an die WinLine Funktion =SUMKTO kein *(-1) gehängt werden, sondern es ist erforderlich in einer anderen Zelle mit dem ermittelten Wert weiterzurechnen.
