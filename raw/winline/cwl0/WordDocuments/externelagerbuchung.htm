Externe Lagerbuchung

 

In der WinLine FAKT besteht die Möglichkeit, die Lagerbuchhaltung mit Buchungsdaten aus einer SQL-Tabelle der Mandantendatenbank durchzuführen. Durch Anwahl des Menüpunkts…

 

1  WinLine FAKT

1  Erfassen

1  Lagerverwaltung

1  Externe Lagerbuchung

 

… können sowohl Lagerbewegungen inklusive Lagerorterfassung, sowie Kommissionierungsbuchungen übernommen werden.

 

 

Der Import dieser beiden Arten von Daten wird in den folgenden Kapiteln detailliert beschrieben:

 

ü  Typ Lagerbuchung
Es können Lagerbewegungen auf Grundlage einer SQL-Tabelle importiert werden.

 

ü  Typ Kommissionierung
Es können Kommissionierungsbuchungen aus einer extra angelegten SQL-Tabelle importiert werden
