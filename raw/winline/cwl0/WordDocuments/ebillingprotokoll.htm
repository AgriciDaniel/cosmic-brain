E-Billing - Protokoll

 

Im Menüpunkt "E-Billing - Protokoll" können alle erfolgreichen Ex- bzw. Importe von Belegen, die im Menüpunkt "E-Billing" durchgeführt wurden, ausgewertet werden.

 

 

Die Auswertung kann unter verschiedenen Einschränkungen erfolgen:

 

Ø  Auswahl

Im Bereich "Auswahl kann bestimmt werden, ob nur importierte, nur exportierte, oder alle Belege ausgegeben werden sollen.

 

Ø  Datumsselektion

Einschränkung der Ausgabe auf einen bestimmten Datumsbereich

 

Ø  Personenkonten

Die Auswertung kann auf einen bestimmten Personenkontenbereich eingegrenzt werden.

 

Ø  Belege

Die Auswertung kann auf bestimmte Belege eingegrenzt werden.

 

Ø  Benutzer

Mit dieser Selektion kann das Signaturserver-Protokoll nur für bestimmte Benutzer ausgegeben werden.
