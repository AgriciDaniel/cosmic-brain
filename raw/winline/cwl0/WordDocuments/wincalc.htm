WinCalc

 

Das WinCalc stellt die alternative zu Microsoft Excel in WinLine dar und bietet u.a. die folgenden Funktionen:

 

ü  Übersicht
Das Look & Feel des WinCalc ist an Microsoft Excel angelehnt.

 

ü  Formeln und Funktionen
Es stehen neben allen üblichen Microsoft Excel Funktionen diverse weitere Funktionen zur Verfügung, welche den Zugriff auf die Daten der WinLine ermöglichen.

 

ü  Ordnerübersicht
Über eine Ordnerstruktur kann ein individuelles Berechtigungssystem für die CalcSheets des WinCalc geschaffen werden.

 

ü  Ex- und Import
Die CalcSheets können als "Microsoft Excel-Arbeitsblatt" (.xlsx) oder im hauseigenen WinCalc-Format (.wcs) nach Windows exportiert werden. Eine Importfunktion für die beiden Dateiformate steht ebenso zur Verfügung.

 

ü  WinLine Integration
Das WinCalc steht, neben dem manuellen Aufruf, an diversen Stellen in der WinLine zur Verfügung:

 

ü  Rechte Maustaste
Über die rechte Maustaste in einer WinLine Tabelle können die Daten mittels Funktion "Ausgabe WinCalc" direkt an das WinCalc übergeben werden.

 

ü  MesoCalc
Im Programm "MesoCalc" steht der Button "Ausgabe WinCalc" zur Verfügung, durch welchen die Daten der gewählten Auswertung an das WinCalc übergeben werden.

 

ü  Cockpit / Power Report
Im Cockpit und dem Power Report kann das WinCalc als Widget eingebunden werden. Neben der Nutzung der Standardfunktionen besteht hierbei die Möglichkeit auf Informationen bestehender der Datenquellen-Widgets zuzugreifen.

Hinweis

WinCalc ist Bestandteil des WinLine BI CORPORATE. Sollte keine entsprechende Lizenz vorliegen, so ist ein Laden und Speichern von CalcSheets nicht möglich und der Ex- und Import steht nicht zur Verfügung.
