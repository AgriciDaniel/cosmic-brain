Belegerfassen - Register "Kopf" - Umwandeln von bestehenden Belegen

 

Soll ein bereits bestehender Beleg in eine weiterführende Belegstufe umgewandelt werden, dann kann im Register "Kopf", nach Angabe der neuen Belegstufe, eine bereits vergebene Laufnummer eingeben bzw. über den Matchcode aufrufen werden. Sollte nur die Laufnummer, nicht aber die Kunden- bzw. Lieferantennummer bekannt sein, so kann direkt in das Feld "Laufnummer" gewechselt und dort nach dem zur Laufnummer passenden Personenkonto gesucht werden.

Hinweis

Neben dem Umwandeln eines bestehenden Belegs im Programm "Belegerfassen" (über das Feld "Laufnummer") kann das Umwandeln auch über die Programme Belege, Belege - Matchcode und Belegmanagement gestartet werden.

 

 

Wenn ein bestehender Beleg umgewandelt werden soll, wird abhängig von der Ausgangs- und Zielbelegstufe unter Umständen eine der folgenden Meldung angezeigt:

 

ü  Bereits gerechneter und / oder gedruckter Beleg der Belegstufe "2 - Auftrag" / "6 - Bestellung"
Bei der Umwandlung eines bereits gerechneten und / oder gedruckten Belegs der Belegstufe "2 - Auftrag" / "6 - Bestellung" in eine Faktura (Belegstufe "4 - Faktura" bzw. "8 - L.Faktura") wird folgende Meldung angezeigt, welche zunächst bestätigt werden muss:



Wird diese Meldung mit "Ja" bestätigt, so kann der Beleg umgewandelt werden. Sollte, wenn die Frage mit "Ja" beantwortet wird, auch die STRG-Taste gedrückt werden, so wird diese Einstellung benutzerspezifisch (in der Datei "MESONIC.INI") gespeichert und die Abfrage zukünftig nicht mehr gestellt.
Bei Auswahl von "Nein" wird die Umwandlung abgebrochen.

 

ü  Bereits gerechneter und / oder gedruckter Beleg der Belegstufe "1 - Angebot" / "5 - L.Anfrage"
Bei der Umwandlung eines bereits gerechneten und / oder gedruckten Belegs der Belegstufe "1 - Angebot" / "5 - L.Anfrage" in eine Faktura (Belegstufe "4 - Faktura" bzw. "8 - L.Faktura") wird folgende Meldung angezeigt, welche zunächst bestätigt werden muss:



Wird diese Meldung mit "Ja" bestätigt, so kann der Beleg umgewandelt werden. Sollte, wenn die Frage mit "Ja" beantwortet wird, auch die STRG-Taste gedrückt werden, so wird diese Einstellung benutzerspezifisch (in der Datei "MESONIC.INI") gespeichert und die Abfrage zukünftig nicht mehr gestellt.
Bei Auswahl von "Nein" wird die Umwandlung abgebrochen.
