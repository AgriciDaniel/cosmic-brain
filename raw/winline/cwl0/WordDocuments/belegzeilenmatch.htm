Belegzeilen-Match

 

Um z.B. im Programm Arbeitsschrittstatus auf eine bestimmte Belegzeile einzuschränken, kann der so genannte Belegzeilen-Match verwendet werden.

 

 

Info

Im Bereich "Info" werden Informationen zum Kunden bzw. zum Beleg angezeigt.

 

Optionen

Über die Option "nur Produktionsartikel" kann festgelegt werden, dass im Suchergebnis nur Produktionsartikel berücksichtigt werden. Bleibt die Option deaktiviert, so werden alle Artikel aus dem Beleg angezeigt.

 

Suchbegriff

Im Feld "Suchbegriff" kann der gewünschte/zu suchende Text angegeben werden.

 

Tabelle

In der Tabelle wird das Suchergebnis dargestellt. Als einzelne Informationen werden hierzu die Zeilennummer aus dem Beleg, die Artikelnummer und Bezeichnung, die Menge, sowie ein Kennzeichen, ob es sich um einen Produktionsartikel handelt, angezeigt.
