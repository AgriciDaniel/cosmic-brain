Belegerfassung - Register "Mitte" - Kontrakte abbuchen

 

Wird das Fenster "Belegerfassen - Artikelerfassung" über den Menüpunkt Kontrakte abbuchen aufgerufen, so werden in der Belegmitte alle Artikel aufgelistet, die im gewählten Kontrakt vorhanden sind.

 

Mengenvorschlag

Je nach Einstellung des "Restmengenvorschlages" in der Belegart wird die "Liefermenge" vorbelegt, wobei grundsätzlich alle Zeilen, auch mit jene mit Liefermenge 0, in den neuen Beleg übernommen werden:

 

ü  0 - Differenz
Bei Teillieferungen wird die noch ausstehende Kontraktmenge vorgeschlagen.

 

ü  1 - verfügbar
Bei Teillieferungen wird die verfügbare, maximal jedoch die noch zu liefernde Kontraktmenge vorgeschlagen.

 

ü  3 - Nullmengen vorschlagen
Bei Teillieferungen wird 0 vorgeschlagen, der Bearbeiter muss die Menge manuell eingeben.

 

ü  4 - Lagerstand
Bei Teillieferungen wird der Lagerstand, maximal jedoch die noch zu liefernde Kontraktmenge vorgeschlagen.

Achtung

Handelt es sich um eine abgeschlossene Kontraktzeile (egal ob manuell oder automatisch) so wird immer die Menge 0 vorgeschlagen!

 

Editieren und hinzufügen von Belegzeilen

In der Erfassungstabelle können die gewünschten Mengen der Artikel nach Bedarf verändert werden. Es ist möglich neue Artikelzeilen, bzw. Zeilen des Typs "2-Makro" (Textbausteine und Makros) hinzuzufügen (ein Entfernen von Zeilen ist jedoch möglich).

Hinweis

Sollen die Kontraktpreise nur bei dem Abbuchen von Kontrakten genutzt werden sollen (WinLine START Applikations-Parameter - FAKT-Parameter - Belege - Kontrakte - Option "Kontraktpreise" auf "1 - nur beim Abbuchen von Kontrakten verwendet"), so können im Programm Kontrakte abbuchen keine neuen Artikelzeilen erfasst werden (auf dieses wird auch entsprechend hingewiesen). Die Möglichkeit neue Zeilen des Typs "2 - Makro" hinzuzufügen bleibt bestehen.

 

Überlieferung von Kontraktmengen

Im Fenster "Belegerfassen - Artikelerfassung" wird bei der Eingabe der Menge geprüft, ob der Kontrakt überliefert wird und eine entsprechende Warnung (lt. Einstellung in den FAKT-Parametern) ausgegeben. Dieses geschieht auch bei manuell abgeschlossenen Kontraktzeilen.

 

Bei Ausprägungsartikeln erfolgt die Warnung im Aufteilungsfenster, je nachdem, ob die Ausprägungen einen eigenen Preisstamm verwenden oder nicht.

Verwendet die Ausprägung einen eigenen Preisstamm, wird die Warnung bei der Eingabe der Menge ausgegeben.

Wenn die Ausprägungen keinen eigenen Preisstamm verwenden, so wird die Warnung beim Druck des OK-Buttons ausgegeben. Dabei wird die Gesamtmenge (Summe aller Ausprägungen) geprüft.

Hinweis

Eine Übererfüllung des Kontrakts wird nur in jener Belegstufe geprüft, die der eingestellten "Erfüllungsmenge" entspricht.

D.h. wenn als Erfüllungsmenge die Bestellmenge eingestellt ist, kann zwar kein Auftrag erfasst werden, wenn die Menge überschritten wird, es kann aber ein Lieferschein mit einer Menge größer der Soll-Menge gedruckt werden!
