Verteilen auf Benutzer / Mandant

 

Grundsätzlich werden die Einstellungen im CRM Daten Cockpit im Bereich "Meine Favoriten" pro Benutzer und pro Mandant gespeichert. Damit diese Einstellungen auch auf andere Benutzer bzw. auf andere Mandanten übertragen werden können, gibt es im CRM Daten Cockpit den Button

 

Favoriten verteilen

 

Ø  Benutzer

Hier kann der Benutzer ausgewählt werden, auf den die aktuellen Gruppen und Listen aus dem Bereich "Meine Favoriten" verteilt werden sollen.

 

Ø  Mandant

Aus der Auswahllistbox kann der Mandant gewählt werden, auf den die Favoriten verteilt werden sollen.

 

Buttons

 

Ø  Ok

Durch Anklicken des Buttons "OK" werden die Listen aus dem Bereich "Meine Favoriten" gemäß den hinterlegten Einstellungen verteilt.

Hinweis

Da die Favoriten bei dem Zielbenutzer durch die Verteilung unwiederbringlich überschrieben werden, erfolgt vor der Verteilung eine Sicherheitsabfrage.

 

 

Ø  Ende

Durch Drücken des Buttons "Ende" wird der Programmbereich geschlossen und keine Verteilung vorgenommen.
