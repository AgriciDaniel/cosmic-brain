Ausprägungsauswertungen

 

Die Auswertung der Ausprägungen findet im Programmpunkt…

 

1  WinLine FAKT

1  Auswertungen

1  Artikellisten

1  Ausprägungsauswertungen

 

… statt.

 

Register "Ausprägungen"

 

In diesem Register kann eine allgemeine Auswertung erzeugt werden.

 

Ø  Hauptartikelnummer von / bis

An dieser Stelle kann eine Einschränkung auf die Artikel vorgenommen werden, welche ausgewertet werden sollen.

 

Ø  Ausprägung 1 von / bis (hier "Größe / Ort) - Ausprägung 2 von / bis (hier "Farbe")

Hier kann auf die Ausprägung eingegrenzt werden.

 

Ø  Charge- / Identnummer von - bis

Hier kann noch eine Einschränkung auf Chargen- oder Identnummern vorgenommen werden.

 

Ø  Zwischensummen

Sowohl bei "Ausprägungen 1" als auch bei "Ausprägungen 2" kann jeweils die Option "Zwischensumme" aktiviert werden. Damit wird im Formular am Ende jedes Artikels ein Summenblock mit den einzelnen Ausprägungen angedruckt.

Hinweis

Wenn bei Artikeln nur eine Ausprägung hinterlegt ist, dann werden keine Summen angedruckt.

 

Ø  Lagerstandsoptionen

An dieser Stelle kann mit Hilfe einer Auswahlliste definiert werden, welche Artikel - aufgrund des Lagerstands bzw. der Lagerbewegungen - in der Liste berücksichtigt werden sollen.

 

ü  0 - Alle Artikel
Es werden alle Artikel berücksichtigt.

 

ü  1 - mit Lagerbewegung
Es werden alle Artikel berücksichtigt, die im Lager zumindest einmal bewegt wurden. Dabei wird der Lagerstand nicht berücksichtigt. Jedoch ist hierbei zu beachten, dass Artikel, die mit derselben Buchungsart und selben Menge zu und wieder abgebucht werden, dadurch einen Lagerstand von 0 haben, nicht in dieser Einschränkung ausgegeben / berücksichtigt werden!

 

ü  2 - mit Lagerstand größer 0
Es werden alle Artikel berücksichtigt, die einen positiven Lagerstand haben. Dabei werden Artikel, die zwar Lagerbewegungen aufweisen, aber deren Lagerstand 0 ist, nicht berücksichtigt.

 

ü  3 - mit Lagerstand ungleich 0
Hier werden alle Artikel berücksichtigt, deren Lagerstand nicht 0 ist, also auch Artikel, die einen negativen Lagerstand aufweisen.

 

ü  4 - mit Lagerstand kleiner 0
Hier werden alle Artikel berücksichtigt, deren Lagerstand kleiner 0 ist.

 

ü  5 - mit Lagerstand gleich 0 und Lagerwert ungleich 0
Hier werden alle Artikel berücksichtigt, deren Lagerstand zwar 0 ist, die jedoch einen Lagerwert aufweisen (egal ob dieser negativ oder positiv ist)

 

ü  6 - mit Lagerstand gleich 0 (unabhängig vom Lagerwert)
Hier werden alle Artikel berücksichtigt, deren Lagerstand 0 ist, unabhängig davon wie hoch der Lagerwert ist.

 

Ø  Hauptartikel andrucken

Ist die Checkbox Hauptartikel aktiviert, werden auch die Hauptartikel mit ausgewertet.

 

Ø  nur Summen anzeigen

Diese Option kann nur dann angewählt werden, wenn eine der Optionen "Zwischensummen" aktiviert ist. Zusätzlich dazu kann die Option nur gemeinsam mit der Option "Hauptartikel andrucken" verwendet werden (diese Option wird automatisch gesetzt, wenn das nicht schon der Fall ist). Damit werden dann nur mehr die Zwischensummen (also die Summen pro Ausprägung) angezeigt. Die Checkbox steht nur zur Verfügung sofern beide Ausprägungen aktiviert worden sind.

 

Register "Chargen"

 

In diesem Register können alle Chargenartikel (mit oder ohne Hauptartikel) selektiv ausgewertet werden (Zugänge, Abgänge, aktuelle Lagerstand, etc.).

 

Ø  Hauptartikelnummer von / bis

An dieser Stelle kann eine Einschränkung auf die Artikel vorgenommen werden, welche ausgewertet werden sollen.

 

Ø  Chargennummer von / bis

Hier kann eine Eingrenzung über die Eingabe der Chargennummer erfolgen.

Register "Differenzliste"

 

Im Register "Differenzliste" können Lagerstandsdifferenzen zwischen Hauptartikel und Ausprägungsartikel festgestellt werden. Handelt es sich um einen Artikel mit Nachkommstellen so ist zu berücksichtigen, dass auf die Nachkommastelle der jeweiligen Artikelgruppe gerundet wird.

Hinweis

Differenzen können im Prinzip nur dann entstehen, wenn z.B. ein Hauptartikel direkt in der Datenbank zu einem Ausprägungsartikel umgewandelt wurde oder wenn ein Beleg versehentlich ohne Aufteilungen gedruckt wurde. Es können auch Differenzen entstehen, wenn der Hauptartikel bei einer Lagerneubewertung nicht berücksichtigt wurde (Hauptartikel wurde z.B. nicht bei der Lagerneubewertung in der "Von / Bis"-Selektion inkludiert).

 

Ø  Hauptartikelnummer von / bis

An dieser Stelle kann eine Einschränkung auf die Artikel vorgenommen werden, welche ausgewertet werden sollen.

 

Ø  Artikel ohne Differenz unterdrücken

Ist die Option aktiviert, so werden Artikel, welche keine Differenzen aufweisen, nicht angedruckt.

 

Ø  Ausprägungen drucken

Ist die Option aktiviert, so werden alle Ausprägungsartikel mit ihrem Lagerstand ausgedruckt.

 

Ø  Nullzeilen unterdrücken

Ist die Option aktiviert, so werden Ausprägungen, bei denen der Lagerstand NULL ist, nicht angedruckt.

 

Buttons

 

Ø  Ausgabe Bildschirm

Mit Hilfe des Buttons "Ausgabe Bildschirm" oder der Taste F5 wird die Auswertung am Bildschirm ausgegeben.

 

Ø  Ausgabe Drucker

Durch Anwahl des Buttons "Ausgabe Drucker" wird die Auswertung am Drucker ausgegeben.

 

Ø  Ende

Durch Drücken des Buttons "Ende" bzw. der Taste ESC wird das Fenster geschlossen.

 

Ø  Filter bearbeiten

Durch Anklicken des Buttons "Filter bearbeiten" kann die Ausprägungsauswertung nach frei definierbaren Kriterien eingeschränkt werden.
