# Layout - Fluent 2 Design System

## Spacing and Proximity

Elements positioned closely together are perceived as meaningfully related. Spacing creates logical content sections without dividers.

### Hierarchy with Empty Space

UI elements with more surrounding space draw greater focus. "White space lets the eye rest and lets people process information."

### Applying Spacing

- **Component**: smaller spacers maintain strong relationships
- **Pattern**: consistent spacing creates familiar visual rhythm
- **Layout**: directs attention to high-importance areas
- **Responsive**: adjust spacing across device scales. Min touch targets: iOS/Web 44×44, Android 48×48

## Grid

### Anatomy
- **Columns** — building blocks; 12-col framework for responsive design
- **Gutters** — negative space between columns, multiples of base unit
- **Margins** — space outside columns, fixed or %, adaptable across breakpoints
- **Regions** — column/row/module groupings

### Grid Types
- **Baseline** — dense horizontal rows for text alignment
- **Column** — most common for web, evenly-spaced vertical fields (typically 12 cols)
- **Manuscript** — single-column with large text blocks and margins
- **Modular** — vertical columns + horizontal rows = cell matrices

## Alignment

- **Vertical**: top/center/bottom align on horizontal plane
- **Horizontal**: left/center/right edges align
- **Object**: align objects centrally, text left
- **Central**: concentrates focus

## Responsive Design

### Breakpoints

| Class | Range | Breakpoint |
|-------|-------|-----------|
| small | 320–479 | < 479px |
| medium | 480–639 | < 639px |
| large | 640–1023 | < 1023px |
| x-large | 1024–1365 | > 1024px |
| xx-large | 1366–1919 | > 1366px |
| xxx-large | 1920+ | > 1920px |

### Composition
- **Responsive**: single layout adapts via media queries
- **Adaptive**: multiple fixed layouts triggered by available space

## Responsive Techniques

- **Reposition** — alter positions as window grows
- **Resize** — adjust sizes and margins
- **Reflow** — rearrange content (single → multi-column)
- **Show/hide** — based on window size/orientation
- **Re-architect** — fork or collapse elements, progressive disclosure
