# Motion - Fluent 2 Design System

## Motion Principles

Motion defines relationships and transitions to help people recognize changes and move toward their goals.

### Four Core Principles

**Functional** — applied with purpose: identify next steps, inform of changes, celebrate accomplishments.
**Natural** — fluid and real, following physical laws (inertia, gravity, weight, velocity).
**Consistent** — unifies Microsoft experiences; strengthens "Unmistakably Microsoft" principle.
**Appealing** — "Delightful animation draws people in."

## Duration and Easing

Balance sluggish vs abrupt. "Make it feel natural and quick by considering the size of the element and the distance it travels." Larger elements need more time.

### Easing Types

- **Linear** — constant speed; use only for rotations etc.
- **Ease-in** — start slow, accelerate
- **Ease-out** — start fast, decelerate
- **Ease-in-out** — slow / fast / slow

## Transitions

"Transitions introduce, dismiss, or change content via an animation."

### Four Types
- **Enter / Exit** — introduce/dismiss UI from off-screen or in-screen
- **Elevation** — depth changes (buttons, drag-and-drop, windows)
- **Top Level** — page-to-page navigation; prefer quick fade over sliding
- **Container Transform** — resize/reposition for responsive layouts

## Choreography

### Staggering
"Staggering is the process of delaying the start of one or more animations." Softens entry of large item sets or directs attention.

For loading identical repeated content: vary offsets programmatically, larger gaps shortening over time. "For most scenarios, a staggered animation is preferred."

### Hierarchy
"Animation hierarchy allows you to direct people's attention to UX elements in a preferred order." Important elements get prominent movement + longer durations. Group less-significant elements with synchronized timing.

## Accessible Motion

Groups potentially impacted: people with vestibular disorders, low vision, screen reader users, those sensitive to visual stimuli.

### Guidelines
- Design and include "no motion" settings (WCAG)
- Keep durations short, movement natural
- Avoid flashes, jarring or sudden movements
- Constrain motion to focused elements
- Consider alternative communication (ARIA live regions for dynamic content)
