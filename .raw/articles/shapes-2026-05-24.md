# Shapes - Fluent 2 Design System

## Overview

"Shapes help make UI personable, easier to process, and recognizable at a glance." Three properties — form, corner radius, and stroke — define all shapes.

## Forms

- **Rectangle** — "The basic shape for most common components and containers" (buttons, textareas, menus, cards, images)
- **Circle** — "avatars and other components displaying or representing people"
- **Pill** — "paths like a slider's track or a toggle's channel"; tags, keywords, selection
- **Beak** — "Offers a reference point for floating surfaces" (callouts, popovers)

Distinguished via:
- **Fill** — defines and emphasizes shapes
- **Border** — identifies bounding containers on unfilled shapes

## Corner Radius

Default for rectangles: 4px. Below 32px: 2px. Larger: 8px or 12px.

| Token | Usage | Value |
|-------|-------|-------|
| None | Navigation bars, tab bars | 0px |
| Small | Small badges | 2px |
| Medium | Buttons, dropdown | 4px |
| Large | Large buttons | 8px |
| X-Large | Button sheets, popovers | 12px |
| Circle | Personas | 50% |

### Avoid Rounded Corners

Between adjacent UI elements within containers and at screen edges (prevents awkward spacing).

## Stroke

### Thickness

| Token | Web | Mobile |
|-------|-----|--------|
| Thin | 1px | 1px |
| Thick | 2px | 2px |
| Thicker | 3px | 4px |
| Thickest | 4px | 6px |

Scale stroke weight proportionally to element size.

### Caps

Use rounded caps for consistency; avoid square endpoints.
