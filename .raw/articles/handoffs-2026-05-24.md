# Handoffs - Fluent 2 Design System

## Overview

A handoff is a transition between workflow stages. Handoffs "keep important content and provide the right tools and support users need to pick up where they left off." Within a single app or across M365 apps.

## Core Principles

- **Guide seamlessly** — Copilot directs users to next logical step
- **Maintain context** — important info transfers; unnecessary elements removed
- **Unify experiences** — cross-endpoint handoffs are intentional, cohesive, user-initiated

## AI's Role

Copilot facilitates handoffs by:
- Reading content for structure and key points
- Reformatting content for new applications
- Improving content (formatting, tone, summarization)
- Recommending optimal applications based on goals
- Learning preferences

## User Intent Levels

- **Strong intent** — specific, goal-oriented → confident suggestions
- **Semi-formed intent** — partial clarity → clarification support
- **Loose intent** — brainstorming → communicate possibilities

## Visual Patterns

Chat responses, artifacts (editable rich content), entities (M365 file representations), side-by-side viewing, inline modules in hub pages.

## CTA Phrases

- **"Create…"** — building new content from existing material
- **"Open in…"** — accessing existing content without transformation
- **"Continue in…"** — moving to deeper functionality elsewhere
- **"Try in…"** — experimental exploration

System message pattern: "Copilot [past-tense verb] [object] [in/from] [App Name]."
