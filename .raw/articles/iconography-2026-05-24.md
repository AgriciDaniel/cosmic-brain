# Iconography - Fluent 2 Design System

Icons represent concepts, objects, or actions with semantic purpose in layouts. They should be recognizable, functional, and easily understood.

## Fluent Icon Collections

The Fluent iconography system is designed to be "familiar, friendly, and modern." Icons are organized into three collections:

- **System icons** — For UI elements like command bars, navigation, and status indicators (open-source under MIT License)
- **Product launch icons** — Representing Microsoft applications
- **File type icons** — Indicating specific files or formats

Resources include a Figma icon library and GitHub repository for developers.

## System Icons — Themes

**Regular**: Wayfinding (downloads, purchases, launches).
**Filled**: Selected states or moments requiring visual weight.

## Icon Sizing

- **12 pixels**: Conveys info but too small for interactions
- Size icons proportional to interaction context
- Larger icons on smaller screens for touch targets

## Product Launch Icons

- Below 48px: simplify in detail to maintain readability
- Above 48px: use full-fidelity versions scaled by factors of four (48, 64, 96, etc.)
- Product icons never replace the Microsoft logo

## File Type Icons

Multicolor file type icons display optimally at 16, 48, and 96 pixel dimensions. Available in SVG and WebP — SVGs offer vector flexibility; PNGs broader browser compatibility.

## Icon Usage Guidelines

### Naming
"Fluent system icons are literal metaphors and are named for the shape or object they represent, not the functionality they provide." Use "Shield" rather than "Security."

### Modifiers
- Always use filled theme for contrast
- Position modifiers in the bottom right corner
- Avoid over-modification

### Color
- Use only solid colors on system icons
- Apply a single color per icon
- Maintain adequate contrast
- Never modify product launch icon colors

### Localization
Consider cultural context and symbol meanings across regions. Validate choices within their intended cultural context.
