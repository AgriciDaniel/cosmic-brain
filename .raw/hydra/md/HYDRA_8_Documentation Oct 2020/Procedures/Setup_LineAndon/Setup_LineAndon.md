Editing Machines/Workplaces and Lines
Configure a production line's machines/workplaces/workstations and the production line itself in the
Configuration of Workplaces and Resources:
Category Workplace category
Machine / workplace / workstation "N" or "P"
Line "L"
Line assignment
Use the Line assignment to assign the corresponding machines/workplaces/workstations to the production
line. Identify the reference aggregate of the production line.
Create a report group
Create at least one report group in the Groups. If required, you can create the report group for a specific
user. Create a global report group if you want all users to make use of this report group.
Assign production line(s) to the report group
Assign production line(s) to the report group. The position field does not affect display in the Line Andon
Board.
Configuration of OEE calculation
This document describes how to configure the OEE calculation.
Data maintenance for (continuous monitoring) orders/OPs
Log on an operation to the production line in order for the Line Andon Board to show a target cycle. Use a
continuous monitoring order/operation for this purpose. Create this order with at least one operation and
the following data:
Field Value
Target cycle Target cycle of the production line
