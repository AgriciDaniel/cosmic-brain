Determination of Current MLE Variant

1  Determination of current MLE variant

Utilization

You would like to configure HYDRA inbound processing. For this purpose, the current MLE variant that is

available in the system has to be determined.

Procedure – for customers

Ask MPDV Support about the MLE variant that is available in your system.

Procedure – for MPDV/customers with advanced training

Enable the HYDRA Professional Mode.

Start the application MLE Basic Configuration.

Determine the currently highest MLE variant for the requested message type.
