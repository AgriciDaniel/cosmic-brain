DMC-MDE: Configuration in DMC

1  DMC-MDE: Configuration in DMC

Overview

The MDE connection includes three basic components:

  The MachineDataManager component manages machine counters, actual cycles and sends data

to  the  HydraMDEWriter.  The  component  sends  data  at  intervals  or  when  statuses  change.  The

MachineStatusProvider component informs about status changes.

  The MachineStatusProvider component manages machine statuses. There are different monitoring

types inheriting from the MachineStatusProvider component ("no monitoring" type).

o  Cyclic monitoring (component: CycleMonitoringMachineStatusProvider)

o  Operating signal monitoring (component: ProductionMonitoringMachineStatusProvider)

  The  HydraMDEWriter  component  writes  dialog  data  for  HYDRA  to  be  processed  in  the  server.

Configure the HydraMDEWriter component as a child of the MachineDataManager component.

Use the FileTransporter component to transfer data files generated by the  HydraMDEWriter to a shared

directory on the server (transaction safety).

HydraMDEWriter

The HydraMDEWriter includes the following configuration parameters:

-  FileTimespan

Specifies the frequency of generating a new data file for processing in the HYDRA server. Possible

values:

o  Month: a new file once a month.

o  Day: a new file once a day.

o  Hour: a new file once an hour.

o  Minute: a new file once a minute.

-  OutputDirectory

Specifies a local directory that stores the data files. If you indicate a relative path, the directory is

identified  based  on  the  current  runtime  directory  (%ProgramData%\mpdv\mdc\[DMC  instance

name]\...).

MachineDataManager: Counter configuration

The MachineDataManager component includes the following configuration parameters:

-  CounterConfiguration

Refers to an XML file that includes the Counter configuration

.

-  Specify the configuration as "[Type] + "://“ + [relative path].

-  The relative path is identified based on the current runtime directory

(%ProgramData%\mpdv\mdc\[DMC instance name]\_default\[Type]...).

SendingIntervalToHydra

Optional parameter; interval in seconds for the cyclic update of counter differences and actual
cycles.

This parameter sends data to the configured HydraMDEFileWriter at the specified interval.

Default interval: 60 seconds

ConfigMDEJtp_ListServiceName

HYDRA ListServiceName to read out counter data from the HYDRA database. When starting the
program, counter data is written into the above-mentioned XML file.

ConfigMDEJtp_JtpConnector

Name of the JtpConnector component you can use to connect to the HYDRA server. (By default:
JtpConnector).

ConfigMDEJtp_RequestInterval

Interval in seconds to update counter data. You can only change existing counter data. (Default
interval: 0  no cyclic updating).

ConfigMDEJtp_ListServiceColumns

You can indicate the columns of the service. If no columns are specified, DMC requests the
following columns from the HYDRA server.

  machine_counter.type

  machine_counter.monitoring

  machine_counter.designation"

  machine_counter.counter

  machine_counter.cyclecounter

  machine_counter.calculation_partitioning



resource.id

These columns are currently required for correct functioning of the MDE. Standard MachineDataManager

configuration:

The counter configuration includes the following configuration parameters:

Configuration of counters

Each CounterConfig section is a counter.

ID

Number of the counter (unique for each machine).

Text

Counter name.

CycleCounter

Stroke counters yes/no; HYDRA option: posting as cycles. If you use several stroke counters, the

system adds up driver data.

Monitoring

Relevant to cyclic monitoring. Specifies if counters are applied for this purpose.

Type

Counter type

  Yield

  Scrap

  Rework

  Problem

Calculation_Partitioning

Currently not used.

MachineStatusProvider: status configuration and status monitoring

The MachineStatusProvider component includes the following configuration parameters:

-  MachineStatusConfiguration

Refers to an XML file that includes the status configuration.

-  Specify the configuration as "[Type] + "://“ + [relative path].

-  The relative path is identified based on the current runtime directory

(%ProgramData%\mpdv\mdc\[DMC instance name]\_default\[Type]...).

OutputMachineLock

Optional parameter; output for the machine lock to send a signal to the driver (machine). This

configured output is set, if you defined the parameter "MachineLock" for the currently active

status in the status configuration.

OutputMachineDowntime

Optional  parameter;  output  (machine  down).  This  configured  output  is  set,  if  the  status  class

"production" is set for the currently active status.

ConfigMDEJtp_ListServiceName

HYDRA ListServiceName to read out status configuration from the HYDRA database. (By default:
MDMachineCounter.List). Status configuration is written into the above-mentioned XML file.

The FileTransporter component includes the following configuration parameters:

-

InputDirectory:

Specifies  the  local  directory  that  stores  the  files  to  be  transferred  (usually  identical  to  the

HydraMDEWriter-OutputDirectory). If you enter a relative path, the runtime directory is used as the

basis.

-  OutputDirectory:

Specifies  a shared directory  in the HYDRA server or  of a network drive. This directory must be

writable. You also have to change the HYDRA configuration in order to read PDV data files from

this directory. If you enter a relative path, the runtime directory is used as the basis.

-  SearchPattern:

Search dialog to restrict the files to be transferred. Use this dialog to define the file extensions that

should be transferred by the FileTransporter. For MDE you can generally use the pattern "*.mdat“.

-

Interval:

Interval in seconds at which DMC checks the input directory for new data files and, if necessary,

transfers these files to the output directory.
