Configuration for WIP Material

1  Configuration for WIP Material

Usage

In  material  and  production  logistics,  it  is  possible  that  output  batches  must  be  processed  in  the  next

process step already, even though they are still running in the current production process (predecessor).

However,  in  order  to  enable  this  processing  of  so-called  WIP  material,  the  appropriate  configuration  is

required.

Configuration

The following configuration has to be provided for the  material type (Master data  Material  Material

type  General) of the output batch/input batch used:

WIP material (Work in Process)

The  identifier  for  WIP  material  processing  has  to  be  set.  It  determines  whether  a  batch  of  this

material  type  may  automatically  be  logged  on  as  the  input  batch  for  the  subsequent  operation

(based on the operation sequence within a production order).
