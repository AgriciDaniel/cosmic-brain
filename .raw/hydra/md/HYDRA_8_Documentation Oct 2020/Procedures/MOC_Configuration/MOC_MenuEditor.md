Menu Editor
The menu editor allows for the menu options to be designed according to the user's requirements.
Existing menus may be changed, new menus may be generated and self-made menus may be deleted.
Load a menu into the configurator.
If you want to change an existing menu, load it into the menu editor. To do so, select the requested menu
in the combo box and choose the "load" function. As a result, this menu is shown in the configurator. To
open the menu, click the "+" character in front of the top menu entry.
Edit a menu
Once you have loaded a menu into the configurator, you may edit it by dragging individual entries by
"drag&drop" from the overview list of all functions to the menu. Existing entries may be moved within the
menu. Please note that menu entries may only be positioned on the level of sub menus. In case you have
not defined sub menus and you drag a menu entry to a category, the system defines a sub menu
automatically. The submenu labeling may still be changed at a later point in time.
Create new menu
You create a new menu by entering the name of the menu to be created in the combo box of the menu
selection. If you enter a name already used for a menu, this particular menu will be overwritten.
The system holds your individual menus with reference to your user name. In case you edit an existing
menu, which has not been generated by the logged in user, the system internally generates a copy
referencing to the user name. Consequently, you edit the user-specific copy. If you delete your copy the
system uses the original version of the menu.
Delete a self-made menu
You can delete your individual menu by selecting this menu in the combo box and clicking the "delete"
button. This deletion process initiated by the user deletes the locally saved menu. The other menus
applying to the whole system are not affected.
