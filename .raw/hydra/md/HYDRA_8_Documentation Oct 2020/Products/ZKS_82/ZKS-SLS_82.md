1  Security Control Center - Overview

Purpose

This function package offers the possibility to present graphically the accesses and access groups and to

display the alerts that might exist. Floor plans of buildings can be integrated as background image. You

can show the location of the accesses and access groups on these plans.

Implementation notes

You use the function package if:



you use HYDRA access control system (ZKS) and want to have a graphic overview of the status

of your accesses and access groups.

Integration

This  function  package  can  only  be  used  if  the  HYDRA  access  control  product  group  is  in  use  (function

package access control management functions).

Features

  Security control center

o  Graphic presentation of accesses and access groups

o  Display  of  the  status  of  accesses  and  of  alerts  that  might  exist  (if  you  use  the  alarm

system)

o

Integration of floor plans of buildings as background image

o  Graphic tools to develop individual layouts
