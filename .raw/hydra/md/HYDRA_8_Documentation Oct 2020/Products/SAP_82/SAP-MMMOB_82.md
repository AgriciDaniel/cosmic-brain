HYDRA Interfacing Module for SAP MM
1 HYDRA Interfacing Module to SAP MM
Summary
Fields of application
The function package provides a communication container (IDoc) by which consumptions and goods
receipt recorded in the MES can be transferred to SAP ECC. Data are transferred in the SAP standard
format.
Implementation notes
You use the function package if you wish:
 to record MES consumptions (with and without relation to batches) and upload them to SAP
 to upload material generated in MES as goods receipt in SAP
 to perform the upload in the SAP standard format and not according to the customer’s
requirements
Integration
The function package is also integrated in the following function packages:
 MPL-MBV – material and inventory management
 TRT-CLV – batch data management
 TRT-CLA – batch data processing
Features
 Interfacing module to connect HYDRA to SAP MM using the MM-MOB interface. Upload of goods
movements using the SAP standard IDoc WMMBID02 (segments E2MBXYH, E2MBXYI):
 Transfer of goods receipts from the production (SAP movement type 101)
 Transfer of goods issues from the production (SAP movement type 261)
 Prerequisite: HYDRA modules (e.g. MPL) generating goods movements are used and technical
details are coordinated (chargeable customization service).
Prerequisites: HYDRA modules (e.g. MPL, TRT) generating goods movements are in use.

HYDRA Interfacing Module for SAP MM
2 Mapping of MM-MOB in HYDRA
Summary
The function package SAP-MMMOB is based on goods movements generated by other function
packages (e.g. MPL, TRT). Goods receipts as well as goods issues are considered in this context.
The interface itself does not perform any further checks. Data consistency has to be ensured by the
generating applications.
Prerequisite
The MES material type has to be configured as subject to uploads for the interface to make sure that
goods movements can be provided.
