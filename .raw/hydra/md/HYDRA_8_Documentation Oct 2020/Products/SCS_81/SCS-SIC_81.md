Purpose

The "HYDRA Service Interface" connects external systems and applications via web services. Using the

services, you can request, receive and process data and therefore use all functionalities that are available

in the HYDRA server.

The customer must purchase the SCS-SIC client license "Service Interface" for each connected client.

For more information on the "HYDRA Service Interface", refer to the  Documentation of the basic license
