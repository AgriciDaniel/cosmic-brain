MES Development Suite

1  Overview

The  MES  Development  Suite  provides  you  with  development  tools  in  order  to  enable  the  customer  to

develop applications and functions independently.

This  document  describes  the  possibility  to  develop  log  elements  for  machine  communication

independently,  which  may  then  be  integrated  in  the  HYDRA  PCC.  Since  this  constitutes  software

development involving programming languages and development environments outside HYDRA, it is not

described  here  in  detail.  Integration  documentation  and  programming  rules  are  provided  separately.

Coordination with / training by MPDV is always required to get familiarized with the technology.

Scope of MDE-PKE license:

Development  framework for  independent  creation  and  configuration  of  drivers  for  connecting  machines,

systems  and  other  peripheral  equipment  via  the  HYDRA  process  communication  controller  PCC,

including comprehensive documentation, sample program (frame) for Delphi and C++ and one man-day

of remote consulting for support and assistance in program development.
