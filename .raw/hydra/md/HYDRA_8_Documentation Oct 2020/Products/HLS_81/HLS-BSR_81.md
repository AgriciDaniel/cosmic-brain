 Overview Assignment of Secondary Resources

Purpose

This  functions  package  allows  the  tools  or  resources  used  to  be  inspected  in  HYDRA  shop  floor

scheduling.

You use this functions package if, in addition to the workplace-related capacity inspection, you also want

to  perform  a  resource-related  capacity  inspection  during  planning  and  these  resources  are  to  be

managed in tool and resources management.

Features

  Capacity inspection of the tools and resources used in HYDRA shop floor scheduling

  Capacity  inspection  accounting  for  the  resources  that  are  configured  for  inspection  in  the  list  of

production resources and tools.

  Display of a conflict list with multiple assignments.

  Display of the resource assignment in the form of a GANTT diagram.

  Graphic display of the required resources incl. staff and qualifications as capacity build-ups.

Requirement: Tool and resources management must be licensed and installed.
