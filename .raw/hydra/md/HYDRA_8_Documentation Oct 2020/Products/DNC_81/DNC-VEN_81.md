1  NC Visualization and Editor

Purpose

The DNC administration treats NC programs or setting data records as resources in the HYDRA system.

This function package allows the display and editing of NC programs to be integrated into HYDRA.

You use the function package when:

  You wish to display and compare NC programs in HYDRA.

  You  wish  to  edit  NC  programs  in  HYDRA.  A  simple  internal  editor  can  be  used  for  this,  or  a

programming tool can be directly integrated if the tool supports this.

Integration

The basic function of the DNC administration is required.

Features

Optimum support for the user in the release or optimization workflow of NC programs:

  Display of NC programs and setting data on BDE/DNC terminals and at PCs in work scheduling,

in the foreman's office, etc.



Integration of external viewers for visualization of the relevant information, incl. print function

  Display of the differences between two versions of an NC program (e.g. between optimized NC

program and original NC program)

  Colored highlighting of the differences in the program lines

  User-friendly programming environment (editor) for editing NC programs

  Saving of the modified NC programs to the HYDRA database



Integration of external programming tools with automatic file transfer at the start and return after

the modification
