1  Display Tooling Sheets

Purpose

DNC  administration  treats  NC  programs  or setting  data  records  as  resources  in  the  HYDRA  system.  In

connection  with  the  resources  BOM  function,  documents  can  be  linked  with  NC  data  records.  These

documents are then available to be displayed on the operator terminal.

You use the function package if:

  You would like to link NC programs in HYDRA with documents and display them on the client and

the terminal.

Integration

The basic DNC administration function is needed.

Features

Displays  additional  information  about  NC  programs  at  BDE/  DNC  terminals  and  at  PCs  during  work

scheduling, in the foreman's office, etc.:

  Transfers  the  file-based  additional  information  from  the  NC  programming  system  if  it  offers  a

suitable interface.

  Visualizes the tooling sheets and similar documents that are assigned to the NC programs or the

operations.

  Displays data using external programs such as MS Word, MS Excel or similar.

  Displays additional information from separate document administration in the HYDRA application

Tools/ resources management and integrates it into the BOM function.
