2  PCC-E63

2.1  General

EUROMAP  63  or  E63  is  a  standardized  file-based  interface  according  to  the  Euromap63  specification,

which is used to exchange data with injection molding machines via FTP server or network drive.

The communication between server (HYDRA terminal or shop floor server) and machine is performed via

file transfer or communication directory. The network (TCP/IP) and the FTP protocol or another protocol

are used to access the file on the communication server for the file transfer from the machine. Depending

on the configuration, HYDRA accesses these files via Windows file access locally or via the network.

The HYDRA protocol module E63 is based on the E63 version V1.05. See also

http://www.euromap.org/downloads/eu63.pdf

The EUROMAP63 interface is not real time capable. The data transfer time is sometimes longer

than the time required for specific partial cycles of the production process. This is due to the

architecture of the file interface of the EUROMAP63 standard.

2.2  Purpose

To  connect  machines  to  the  HYDRA  system,  HYDRA  provides  an  EUROMAP63  client  (PCC-E63)

integrated in the software. This client has been realized as protocol module in the HYDRA-PCC (Process

Communication Controller).  You can  use the client to  read all data fields (tabs) of the machine that are

provided by the EUROMAP63 interface of the machine. This access can be used for data of the following

HYDRA product groups:

-  MDE (counter, cycle)

-  PDV (process values)

-  DNC (setting values)

2.3.3 Connection test to E63 machine

With the EUROMAP63 standard,  you  can test the communication  independently of the shop floor client

(PCC). Below, MPDV provides a recommendation of how to test the machine communication.

The  customer  is  responsible  for  the  error-free  communication  between  machine,  middleware  (FTP/file

server, eFactory, etc.) and deployment directory of the E63 driver.

The  recommended  procedure  for  testing  the  E63  machine  communication  is  general.  The

specific  details  depend  on  the  technical  realization  of  the  machine  manufacturer.  Only  the

machine manufacturer can provide detailed information.

How to proceed

1.  Check  the  error-free  network  communication  between  machine  (usually  FTP  client),  server

(usually FTP server) and PCC. You can use common network tools like Ping, Tracert and ftp for

the test.

2.  When the network connection is guaranteed, you must test the data exchange between machine,

server  and  PCC.  Use  the  logs  of  the  machine  and  the  FTP  server  to  find  out  whether  the

connection was successfully established.

3.  Note the examples of the manufacturers.

4.  Ensure that the Windows user, which is used to run the PCC, has read and write access for the

directory where the EUROMAP63 files of the relevant machine are stored.

5.  When  the  connection  to  the  machine  is  established,  you  can  manually  test  the  data  exchange

between terminal and machine. Copy "getid.job" and "sess0001.req" to the transfer directory. The

machine monitors the session directory and writes the parameters in a second file "getid.dat".

2.4

Integration in HYDRA

The protocol module is integrated in the HYDRA-PCC. For further information, refer to the manuals of the
products SCS-PCP and SCS-PCB.

4.2  Installation FTP server

4.2.1 General Notes

The  FTP  server  "Internet  Information  Services"  (IIS)  of  Microsoft  cannot  process  specific  FTP

commands (e.g. LISTDIR *.*) with some machine manufacturers (e.g. DEMAG). Many machine

manufacturers do not support the IIS.

Use  alternative  products  like  the  FileZilla,  for  example,  or  follow  the  recommendations  of  the  machine

manufacturer.

4.2.2 Sample installation FileZilla-FTP-Server

Important:  This  is  only  a  configuration  example.  The  actual  installation  must  be  based  on  the

specifications of the machine manufacturer.

The  FileZilla  server  is  a  graphic  (Windows  and  Linux)  open  source  FTP  server  for  different  platforms.

Using  the  FileZilla  server,  files  can  be  exchanged  quickly  and  easily  between  the  file  directory  and  the

clients via ftp.

You can download the free FileZilla server at: https://filezilla-project.org

Follow  the  installation  assistant  of  the  "FileZilla  Server".  Be  careful  to  "Install  as  service".  If  required,

unblock the FileZilla server in the firewall.
