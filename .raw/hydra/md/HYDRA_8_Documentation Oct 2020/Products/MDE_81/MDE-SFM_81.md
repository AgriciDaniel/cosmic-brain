1  Overview of Graphic Machinery

Purpose

The graphic machine park provides  a visual presentation  of the company's machine  park at a specified

level (workshop, foreman's area, …). Not only does this function visualize master data, but it also presents

in real time actual data  recorded in MDE and BDE.

Implementation considerations

You use the function package if:

  You  would  like  to  have  a  graphical  presentation  of  your  company's  available  machines  that  is

supplemented by current actual data.

Integration

Current MDE data (e.g. machine status, current quantities) and BDE data (e.g. logged on operations) are

accessed for the presentation. Additionally, there is an option to display the current status of the terminal

or ZKS accesses.

Features

  Graphical presentation

o  Graphical  presentation  of  the  company's  machine  park  in  a  hall,  department,  foreman's

area or the like.

  Two-level structure

o  Two-level  structure  from  separate  machines  and  their  assignments  to  machine  groups,

cost centers and lines.

  Display of current machine state

o  Display of the current machine state using different colors

  Tool tip

o  Detailed information in the info window (Tool tip)

  Quantity progress

o  Bar  chart  provided  to  visualize  the  finished  actual  numbers  of  units  compared  to  the

planned target number of units.

  Layouteditor

o  Graphic  editor  used  to  create  hall  layouts  with  individual  placement  of  the  machine

symbols, machine groups and production lines.

Usage

The graphic machinery provides a vivid presentation of essential workplace and production information in

spatial/temporal contexts. The user can create and display different representations (so-called layouts) of

all organizational units (e.g. halls, departments) as required.

Graphic machinery can serve as an indicator for the production manager and also provides a current, large-

screen overview of production statuses on the shop floor.

Integration

In the graphic machinery, you can visualize up-to-date status information of objects from various HYDRA

products:

  BDE/MDE: Machines, groups, line groups

  MW: Terminals

  WRM/EMG: Resources (no file-based resources, no DNC resources)

  MPL: Material buffers

  ZKS: Accesses, access groups

Requirements

The relevant objects to be visualized in the graphic machinery must be set up in the system master data.

Appropriate layouts must have been prepared using the layout editor.

Structure of graphic machinery

The graphic machinery shows various layouts of different organizational units. These may be generated by

the user as required.

The following field descriptions refer to the "Layout" table and the "Layout" detail view:

Layout

Layout name, e.g. "Hall 1"

Comment

Comment further describing the layout.

Order

By determining an order/sequence and sorting the table by the "order" column, a particular layout is

always displayed by default when the function is called up. Please note that the defined order is not

user-related.

Responsibility area

A  responsibility  area  can  optionally  be  assigned  to  a  layout.  In  this  case,  the  layout  will  only  be

available to a user with authorization for the entered responsibility area.

Internal ID

Upon insertion of any new layout, the system assigns this number automatically; it cannot be modified

by the user.

File name

The configuration of the actual layout is saved in a file in the server. The system automatically assigns

the file name when a new layout is added and cannot be modified by the user.

Type

Always "N"

Modified by / Modified on

This information refers to the latest editing of a layout entry in the table, not to the latest editing of the

graphic layout.

These two drop-down list boxes can be used to search for specific objects in layouts. The object type

Setting the refresh interval

The  refresh  interval  refers  to  the  time  interval  between  two  update  runs  in  the  graphic  machinery.  This

interval can be set customer-specifically via an INI data configuration.

The value corresponds to the time interval in milliseconds between two update runs.

The  default  value  of  60000  milliseconds  (60  seconds)  applies,  if  a  value  less  than  60000

milliseconds (60 seconds) is entered or if nothing is entered.

Configuration:

Ini configuration name:

MPARK

Section:

Key:

Value:

MPARK2

REFRESHRATE

240000 (corresponds to 4 min)

Disabling offline messages

If the graphic machinery cannot establish a connection to the server (offline), the application displays an

error message every time you request data.

You might not want this behavior, especially if you use the full screen mode. Configure the INI configuration

as follows to prevent the error message from being displayed:

Usage

The layout editor of the graphic machinery enables the user to "design" so-called layouts for freely definable

organizational units (e.g. halls, sections, other units, etc.).

Integration

The layout editor is integrated in the graphic machinery application and is called up from there using the

 function key.

Prerequisite

The relevant objects to be displayed in a layout have to be set up in the system master data. A layout entry

must have been defined in the graphic machinery .
