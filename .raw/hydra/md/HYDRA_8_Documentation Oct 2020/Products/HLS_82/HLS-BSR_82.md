 Overview Assignment of Secondary Resources

Purpose

This  function  package  allows  for  the  tools  or  resources  used  to  be  checked  in  HYDRA  Shop  Floor

Scheduling.

You  use  this  function  package  if,  in  addition  to  the  workplace-related  capacity  check,  you  also  want  to

perform a resource-related capacity check during planning and these resources are managed in the Tool

and Resources Management module.

Features

  Capacity check of the tools and resources used in HYDRA Shop Floor Scheduling.

  Capacity check accounting for the resources that are configured for checking in the list of production

resources and tools.

  Display of a conflict list showing multiple assignments.

  Display of the resource assignment in the form of a GANTT diagram.

  Graphic display of the required resources including staff and qualifications as capacity build-ups.

Requirements: The Tool and Resource Management module must be licensed and installed.
