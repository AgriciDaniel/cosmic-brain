1  Security Control Center - Overview

Fields of application

This function package allows for entrances and entrance groups to be presented in graphics and to show

any alerts that might exist. The location of entrances and entrance groups can be pointed out by inserting

ground plans of buildings as background image.

Implementation notes

You use the function package if you

  use the HYDRA access control system (ZKS) and wish to get a graphic overview of the status of

your accesses and access groups.

Integration

This function package can only be used if the access control module is used in HYDRA (function package

“access control management functions”).

Features

  Security control center

o  Graphic presentation of accesses and access groups

o  Presentation of the status of entrances and possible alerts (if the alert system is in use)

o

Insertion of ground plans as background image

o  Graphic tool for the creation of separate layouts
