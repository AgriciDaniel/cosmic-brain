Export of NC Programs and Setting Data

1  Export Interface DNC

Summary

In  connection  with  DNC  programming  systems,  it  might  be  reasonable  to  transfer  DNC  data  to  these

systems,  e.g.  to  forward  the  DNC  files  changed  in  HYDRA  or  recorded  by  the  machine  to  the

programming system.

Functions

Enterprise Integration Service to transfer NC programs and HYDRA setting data to external NC servers.

Please  note:  A  transfer  concept  needs  to  be  defined  and  the  relevant  transfer  procedures  have  to  be

customized to implement this function for customers. The involved services for concept, customizing and

implementation are not covered by the license.
