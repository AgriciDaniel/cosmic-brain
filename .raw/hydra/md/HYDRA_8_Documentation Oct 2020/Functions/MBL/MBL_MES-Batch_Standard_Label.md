1  Standard Label
Usage
You use the standard label as a part of Material and Production Logistics and also in Tracking & Tracing
in order to be able to label WIP material in particular, so that it can be identified later.
Integration
The following posting events trigger a label to be printed:
  Output batch change
  OP interruption
  OP logoff
Features
The label includes the following information resulting from the movement data or from the entry process.
