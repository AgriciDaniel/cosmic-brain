1  Mapping of MM-MOB in HYDRA

Summary

The function package SAP-MMMOB is based on goods movements generated by other function

packages (e.g. MPL, TRT). Goods receipts as well as goods issues are considered in this context.

The  interface  itself  does  not  perform  any  further  checks.  Data  consistency  has  to  be  ensured  by  the

generating applications.

Prerequisite

The  MES  material  type  has  to  be  configured  as  subject  to  uploads  for  the  interface  to  make  sure  that

goods movements can be provided.
