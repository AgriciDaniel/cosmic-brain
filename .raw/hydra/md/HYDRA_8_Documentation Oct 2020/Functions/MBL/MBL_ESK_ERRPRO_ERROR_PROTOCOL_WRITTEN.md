ERRPRO.ERROR_PROTOCOL_WRITTEN

1  ERRPRO.ERROR_PROTOCOL_WRITTEN

Usage

The escalation can be used to be informed on errors resulting from failed plausibility checks.

Integration

The escalation will always be triggered if the applications write also an entry into the dialog error log.
