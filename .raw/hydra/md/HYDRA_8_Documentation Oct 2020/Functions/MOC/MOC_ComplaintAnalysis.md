Purpose

The complaint analysis allows for complaints to be evaluated in different ways using pivot functions. These

functions  provide  different  presentation  options,  e.g.  the  graphic  shows  the  complaint  details  including

reasons for each complaining party over a specified period of time. Use these analyses to identify the core

areas where action is required.

Integration

The  complaint  analysis  function  only  evaluates  complaint  management  data.  In  this  context,  you  can

distinguish between complaint header data and complaint detail data.

Selection criteria

Selection criteria are self-explanatory and not described separately.

Toolbar

There are no other special function buttons in addition to the standard functions/features.

Detail applications "Graphic complaint analysis“

Data is presented in a pivot table including bar charts. Different application functions are available to display

data. The data basis is restricted to the complaint data you have selected beforehand by entering selection

criteria.

This document does not describe the general pivot functions in more detail. The paragraphs that follow only

describe the basic functions of this evaluation/report.

Pivot evaluations/reports provide the following benefits:

  You can quickly summarize and present large amounts of data.

  You can exchange rows and columns to have the source data summarized differently.

  You can use simple filters by “drag and drop” including detail filters.

  The interactive way of presentation allows you to summarize and analyze data in different formats

and using different calculation methods.

Detail applications "complaint analysis list“

The complaint analysis list shows the complaints including referenced data that have been filtered on the

basis of the used selection criteria. Usually, the referenced data corresponds to the field list of the pivot

analysis.
