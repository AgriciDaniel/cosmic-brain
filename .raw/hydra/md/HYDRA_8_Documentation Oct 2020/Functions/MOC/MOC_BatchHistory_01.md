Usage

This batch history function is used to display all executed modifications for a batch.

Integration

Each executed modification of batch data is documented. This refers to both manual modifications in the

system and modifications that occur due to production flow, e.g. a status modification after processing  a

batch or after the minimum storage time expires. In this way, the batch data modifications are traceable.

The selection of the modifications or the log is made using the batch number that the user must enter and

an  evaluation  period.  A  list  is  displayed  that  shows  all  of  the  modifications  of  the  batch  entered  in

chronological sequence.

Selection criteria

The following selection criteria are available in the application:

Batch number

Display of batch history for the selected batch number

Material buffer

Display of batch history for selected material buffers

Operation

Display of batch history for selected operation

Created on ... to ...

Display of batch history is limited to the selected date
