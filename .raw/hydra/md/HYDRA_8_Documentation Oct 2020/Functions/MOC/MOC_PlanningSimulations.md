Usage

This function shows stored simulations including their KPIs, which may be compared with each other. The

KPIs for the simulations are provided in tabular form. For the presented simulation the best KPI value is

highlighted in green and the worst KPI value is shown in red. The detailed screen on the right-hand side

shows the KPIs of the currently selected planning.

Selection criteria

The application provides the following selection criteria:

Plans created between

If these selection fields are filled out, only the simulations created within this selected period of time will

be displayed.

Planning run

Using this selection field, simulations may be selected based on their memory ID ("planning run" field).

Comments

Using this selection field, simulations may be selected based on their comment.

Once a simulation has been selected, it is opened in the planning board.
