In order to assign FMEA rating numbers, the following three master data categories are required:

  Catalog to assign a factor B for the assessment
  Catalog to define likelihood of occurrence A.
  Catalog used for likelihood of detection E.

The three catalogs are integrated and displayed in one catalog.  A differentiation is made by assignment

(A, B, E, etc.).

By default, the process and product assessment catalogs for the catalog sorts "A, B, E" according to DGQ

("German Quality Society"), VDA volume 4 are included.

Purpose

Using this function, you can create and manage FMEA rating numbers that are assembled in catalogs.  The

entries are sorted in B, A and E assessments.

  Assignment of factor B for the assessment
  Definition of the likelihood of occurrence A
  Specifying likelihood of detection E

Integration

You need the application to process FMEAs.

On creating an FMEA, the user needs to select the catalog. This way, the user can assess the elements

Failure and Status of measures using the assigned catalog entries.

Requirements

The licenses FMEA-EVS and FMEA-VDF are required for this function.

Selection criteria

The application provides the following selection criteria:

Assessment catalog

  Enter the required catalog number.

Name of assessment catalog

The user can enter the required catalog designation.
