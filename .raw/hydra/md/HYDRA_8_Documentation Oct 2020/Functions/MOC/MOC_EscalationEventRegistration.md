1  Registered Events

Overview

Usage

Escalations can be chosen from a list. The list  is provided by  the system. It is  not  possible to add new

entries.

Selection criteria

The application provides the following selection criteria:

Event

The event triggers an escalation. Applications generate the event if specific situations occur.

Using the search function, an event may be chosen from the list of available events. It is not possible

to enter events that do not exist.

Class

By defining the class, escalations can be assigned to a product and/or product group.

Category

Escalations can be classified as "technical" and "application-related" via the category.
