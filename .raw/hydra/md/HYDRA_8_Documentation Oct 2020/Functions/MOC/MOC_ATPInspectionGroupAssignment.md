This  document  describes  the  application  "ATP  inspection  group  assignment”  in  the  Manufacturing

Operation Center (MOC).

Purpose

You use the function to assign material types or materials to the configured ATP inspection groups.

Integration

In order to visualize expected material consumption in graphical detailed planning, material types must be

assigned to the ATP inspection groups stored in OPs.

Requirements

You have configured material types and ATP inspection groups in master data.

Selection criteria

The application provides the following selection criteria:

ATP inspection group

Selects the ATP inspection group

Material type

Selects the material type.

Material

Selects the material.

ATP Inspection Group Assignment

Several material types or materials can be assigned to an ATP inspection group.

Material type

Material type to be assigned to an ATP inspection group.

Material

Material to be assigned to an ATP inspection group.

Each material type can be assigned to only one ATP inspection group.

Only material types configured in the  application "Material types"  are available during creation

and changing of a data record.
