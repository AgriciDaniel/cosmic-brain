Purpose
User fields offer the possibility to store and, if necessary, display further project-specific information in the
system besides the fields that are available by default. Therefore, 1-n user fields are assigned to the user
field key to show them with the relevant value at specific objects (e.g. operation).
This function can be used to create/change unique user field keys in the system.
Integration
User field keys always exist in relation to the different objects in the system. For further information, refer
to the documentation MBL_Userfields.pdf.
Editing functions
The relevant functions "create" or "edit" are used to create a new user field or to change it.
