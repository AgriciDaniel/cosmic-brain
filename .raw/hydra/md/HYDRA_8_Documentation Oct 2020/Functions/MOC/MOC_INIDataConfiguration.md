INI Data Configuration

Summary

Menu

System Administration  System Settings  INI Data Configuration

Transaction code

inidcfg

Function authorization

inidcfg.*

Purpose

The INI Data Configuration function can be used to add further parameters/value pairs to an existing INI

configuration or to change them.

Integration

The single functions and applications individually define which INI configuration is used in the system and

which potential entries exist for them.

Requirements

You have already created an INI configuration, which is added by further parameters/value pairs.

Field Descriptions

Section

Section name

Key

Unique key. The number behind the key is to be incremented if several entries are to be defined for

the key.

Value

The value associated with the key.

 Note: [TAB] , [RETURN] are not valid entries.

Active

Activates the entry

Comment

Comment field to describe the entry
