Usage

In the Workflow roles application, roles can be defined and administered for workflow management. The

actual filing/creation of roles, however, is performed in the MES workflow management server.

Selection criteria

The following selection criteria are available to the user:

Role name

Name of role. Please note: wildcard entry is not possible.

Workflow Roles Detail Application (Table)

The Workflow roles detail  application includes a tabular overview of the groups  created  and the related

attributes.

The  data  available  in  the  table  are  described  below.  These  data  might  not  be  shown  by  default.  In  this

case, they can be added using the column selection.

Role name

Role name

Role designation

Role designation

Editing Functions

To create new workflow roles, or edit or delete existing ones, please use the buttons provided. There is

no function to copy workflow roles.
