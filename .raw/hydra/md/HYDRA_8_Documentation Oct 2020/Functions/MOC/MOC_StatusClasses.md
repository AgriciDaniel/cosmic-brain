Status classes are created to group and evaluate  workplace/ machine statuses into user-related classes

independently from the HYDRA resource performance accounts. When the selection mask is called up,

the system lists all of the status classes that have already been defined.

Usage

Create  status  classes  if  you  would  like  to  make  use  of  evaluations  of  such  respectively.  The  status

classes are then assigned to the relevant status during the status assignment process.

Define a unique number for it.

The abbreviation is used to create a link to the status, which is why it must be unique.

The status class Designation is used for display purposes in the various evaluations.

In  order  to  keep  the  status  class  abbreviations  consistent  with  the  RPA  abbreviations,  we

recommend that you enter the status class abbreviation in upper case.

Integration

The  status  classes  can  also  be  evaluated  in  the  various  MOC  evaluations  in  addition  to  the  RPA  and

status evaluations.

The status classes can be assigned to the separate status types in status assignment.

Field descriptions

Status class

Unique status class number

Status class abbreviation

Abbreviation of the status class. It must be unique. Recommendation: Use upper case letters.

Name of the status class
