fmea

The Failure Mode and Effects Analysis (FMEA) is a targeted method to identify potential failures at an early

stage.  Using this method, you assess the risks resulting from failures and develop countermeasures. Each

FMEA is assigned to a team.  You can request this application in the function FMEA overview by clicking

the icon "Team" in the toolbar.

Purpose

This function allows to create a team with any number of members for a specific FMEA.

Integration

You can only request this application by selecting a specific FMEA in the function FMEA overview and by

clicking the icon "Team" in the toolbar.

Requirements

In order to create individual team members, master data must be set up. Only team members from the

following areas can be set up:

Field descriptions

Team type

Alphanumerical field for free allocation of an FMEA number

Team member

Alphanumerical versioning of an FMEA number

Name 1, Name 2, Name 3

Display of field content of "Name 1", "Name 2" and "Name 3" from the master data entries.  The

customer name and the content of the address fields 1 and 2 are displayed for customers. The last

name, first name and initials are displayed for external persons.
