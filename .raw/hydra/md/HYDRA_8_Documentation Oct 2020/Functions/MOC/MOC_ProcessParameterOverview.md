The overview of the process statuses of process parameters and machines is used for process analysis

in quality management.

Usage

In  this  application,  the  current  status  of  individual  characteristics  is  indicated  in  accordance  with  limit

value  violations.  This  means  the  status  of  the  characteristics  and/or  process  parameters  is  always

indicated on the basis of the latest status transmission received. This is also implemented in the form of

color highlighting, too. Based on the status of a machine's process parameters, an overall status for the

machine is also generated and displayed.

Integration

The  application  is  similar  to  the  Limit  value  violations  application,  whereby  here  only  the  latest  value  in

time is indicated as the status.

Selection parameters

The following selection criteria are available in the application:

Machine

The desired machine can be selected via the machine pool application.

Process parameters

It is also possible to enter a process parameter.

Event time stamp

By limiting the event time stamp, exact time intervals can be selected.

Violation

In addition, a drop down list can be used to select according to the violation.

Table Detail Application

The table shows all process characteristics of the machines with process data collection. This is limited

by the activated selection criteria. Based on the indicated process value violation, a status for the process

parameter is formed and an overall status of the machines is generated from all statuses of the machines'

process characteristics. The following applies here:

Process parameters

OK:

green display

Action/warning limits violated:  yellow display

Tolerance limits violated:

red display

Overall status of machines

All process parameters OK:

green display

Action limits violated for at least one process parameter:

yellow display

Tolerance limits violated for at least one process parameter:

red display
