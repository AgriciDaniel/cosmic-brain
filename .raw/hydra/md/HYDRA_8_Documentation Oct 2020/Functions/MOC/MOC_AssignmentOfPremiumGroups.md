aspgrp.*

This  application  provides  for  the  static  assignment  of  machines  to  premium  groups.  This  static

assignment  is  one  option  to  build  premium  groups  and  to  assign  recorded  data  to  them.  A  separate

document describes the different possibilities of building premium groups.

A machine may only be assigned to one premium group.
