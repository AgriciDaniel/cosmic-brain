You  can  use  the  application  Work  plan  -  edit  long  texts  of  operation  to  collect  additional  texts  for  the

operation. You can record only one long text per operation.

Please note

  Long texts can also be transferred using the system’s info interface (record type "AI"). For further

information on the interface, please refer to the corresponding interface documentation.

  The terminal shows the long texts relating to operations.

Selection criteria

The application provides the following selection criteria:

MES work plan number

Enter the MES work plan number to select the long text of a specific operation of the work plan. The

MES work plan number is the combined work plan/operation number.

Field Descriptions

The fields of a long text pertaining to orders are described here.

Editing functions

Please use the available buttons to create or edit operation long texts of the work plan. A copy function

for operation long texts is not planned.
