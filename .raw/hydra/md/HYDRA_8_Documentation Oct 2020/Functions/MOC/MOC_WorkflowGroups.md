1 Workflow Management - Workflow Groups
Overview
Menu Master data – Workflow management – Workflow groups
Transaction code wfgr
Function authorization wfgr
Usage
In the Workflow group application, user groups can be defined and managed for workflow management.
The actual filing/creation of the groups, however, is performed in the MES workflow management server.
Selection Criteria
The following selection criteria are available to the user:
Group name
Name of group. Please note: wildcards are not supported.
E-mail address
E-mail address of group. Please note: wildcard entry is not possible.
Workflow Groups Detail Application (Table)
The Workflow group detail application includes a tabular overview of the groups created and the related
attributes.
The data available in the table are described below. These data might not be shown by default. In this
case, they can be added using the column selection.
Group name
Name of group
Group designation
Designation of group
E-mail address
E-mail address of group
