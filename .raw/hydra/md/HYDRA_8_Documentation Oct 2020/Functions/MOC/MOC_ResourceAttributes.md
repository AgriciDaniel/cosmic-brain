This document describes the application "Resource attributes" on the client.

Purpose

This application allows for the maintenance of values for resource attributes.

Please note:

Resource attributes (indirect users fields) are available for the object resources (HYDRA WRM/ DNC), the

CAQ inspection plans (CPPL) and CAQ inspection requirements (CPAN).

Toolbar

 Edit

Opens the dialog for editing a comment.
