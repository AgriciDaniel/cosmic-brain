You can use the application Work plan - edit operations to create or edit operations for work plans.

Consequently, real orders may be generated from the work plans that are also often referred to as "empty

envelope" for orders.

Selection criteria

The application provides the following selection criteria:

Work plan

Enter the work plan number to select the operations of a specific work plan.

OP

You can narrow down the selection to one single operation of a work plan.

Sequence

This field  is  only  relevant  if  sequences  are  used  in  the  system.  In  this  case,  the  selection  can  be

restricted to a specific sequence.

Field Descriptions

Operation fields are described here

Editing functions

Please use the available buttons to create or edit work plan operations.

The order (header) of the work plan must already exist in order to be able to create an operation.

Operations may only be copied within the work plan.
