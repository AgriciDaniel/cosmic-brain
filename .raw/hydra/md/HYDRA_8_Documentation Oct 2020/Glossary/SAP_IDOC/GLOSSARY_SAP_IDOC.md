1  SAP - Intermediate Document

Definition

IDocs are included in the SAP environment  as containers for a data exchange between systems. IDocs

may be flat or map multi-level hierarchies.

Each IDoc consists of the following components:

Control record - includes information on the IDoc type, the header line, sender and recipient

Data record - the data themselves are represented here as flat ASCII file in segments

Status record- includes information on the status of the IDoc, e.g. error messages.
