Order Status

1  Order Status

Definition

The  order  status  represents  the  current  status  of  a  production  order.  Possible  statuses  are  (default

values):

 Prepared:

The order has not yet been started

  Started:

The order has already been started, i.e. at least one operation has been started.

 Finished:

The order has been finished, i.e. all recordable operations have been finished.
