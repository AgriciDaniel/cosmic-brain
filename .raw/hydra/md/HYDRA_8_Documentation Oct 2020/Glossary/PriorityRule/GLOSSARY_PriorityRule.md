Priority Rule

1  Priority Rule

Synonyms

Planning strategy

Definition

Within the framework of the automatic planning function, the priority rule specifies in which order (priority)

operations are to be scheduled.

Example

The system provides priority rules for the following planning types (machine scheduling):

1.  Sort rules for variable machine scheduling

2.  Targeted machine scheduling

3.  Rule-based machine scheduling
