SAP - Application Link Enabling

1  SAP - Application Link Enabling (ALE)

Definition

Application Link Enabling (ALE) is a technology to create and run distributed applications (R/3, R/2, third-

party  system).  ALE  enables  the  exchanges  of  business  and  controlled  information  and  data  while

maintaining the consistency of data management by loosely coupled (asynchronous) systems.
