KASSE net

 

Um eine Signatureinheit bzw. Online-Signatur von mehrere Workstations aus anzusprechen, wird die Lizenz "KASSE net" benötigt, andernfalls kann nur von jeweiligen Workstation aus signiert werden, wo die Signatur eingelesen wurde.

 

Hinweis

Wenn ein einziger Terminalserver verwendet wird und eine Online-Signatur verwendet wird, wird keine KASSE net gebraucht, da immer von der Workstation erfasst wird, wo auch die Signatur eingelesen wurde.

 

Es kann immer nur jeweils ein Kartenlesegerät pro Workstation bzw. Server aus der WinLine angesprochen werden.

 

Wenn auf eine Workstation/Server mittels RDP-Protokoll zugegriffen wird, kann dort nicht die Signatur eingelesen werden. Es kann generell kein Kartenlesegerät angesprochen werden, wenn das Kartenlesegerät am selben Rechner hängt, wie jener, auf den gerade mittels RDP zugegriffen wird. In so einer Konstellation empfiehlt es sich, die Signatureinheit auf einer Workstation bzw. auf einem anderen Server anzuschließen und einzulesen oder auf eine Online-Signatur zurückzugreifen.
