Einrichtung des WinLine Server ungleich WinLine Server

 

Im Zuge des Installations Wizards (MSM/Installations Wizard) darf die Option "WinLine Server einrichten" NICHT aktiviert werden.

 

Vielmehr muss das, durch die Installation entstandene EWL-Verzeichnis, als Unterordner jenes WinLine-Verzeichnisses, auf dem Rechner eingefügt werden der als WinLine Server eingerichtet werden soll.

 

In weiterer Folge muss die Einrichtung der EWL über den ADMIN (auf jedem Rechner auf dem der WinLine Server laufen soll) durchgeführt werden.
