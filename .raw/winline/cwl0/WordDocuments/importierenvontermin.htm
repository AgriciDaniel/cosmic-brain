Importieren von Termin

 

In Microsoft Outlook hinterlegte Kalendereinträge können über das Add-In "WinLine Termin" importiert werden. Hierfür wird der Kalendereintrag ausgewählt und per Klick auf "WinLine Termin" übernommen.

 

 

Es wird eine CRM-Aktion "Outlook Termin Import" angelegt und kann über den List-Assistenten in bestehenden WinLine Kalender hinzugefügt werden.
