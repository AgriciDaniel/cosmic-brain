SALESSUMEXT

 

Mit dieser Funktion wird eine Summenwert aus der Statistik auf Grundlage von Artikel, Personenkonto, etc. berechnet und ausgegeben.

Hinweis

Alle Selektions-Parameter sind optional und müssen nicht mit einer Eingabe versehen werden (nicht benötigte Parameter mit "" hinterlegen). Des Weiteren können auch mehrere Parameter gleichzeitig angeben werden.

 

Syntax

=SALESSUMEXT (Artikelnummer, Personenkonto, Artikelgruppe, Artikeluntergruppe, Vertreter, Datum von, Datum bis, Wert, Verkauf/Einkauf)

 

Ø  Artikelnummer (Nummer in "")

Hinterlegung bzw. Verweis auf die zu berücksichtigende Artikelnummer; wenn keine Artikel-Auswahl gewünscht ist, muss "" angegeben werden

 

Ø  Personenkonto (Konto in "")

Hinterlegung bzw. Verweis auf das zu berücksichtigende Personenkonto; wenn keine Konten-Auswahl gewünscht ist, muss "" angegeben werden

 

Ø  Artikelgruppe (-1 / 0 / 1 / 2 / …)

Hinterlegung bzw. Verweis auf die auszuwertende Artikelgruppe (Nummer); wenn keine Gruppen-Auswahl gewünscht ist, muss -1 angegeben werden

 

Ø  Artikeluntergruppe (Gruppe in "")

Hinterlegung bzw. Verweis auf die zu berücksichtigende Artikeluntergruppe (5x5stellige Nummer); wenn keine Gruppen-Auswahl gewünscht ist, muss "" angegeben werden

 

Ø  Vertreter (Zahl)

Hinterlegung bzw. Verweis auf den zu berücksichtigenden Vertreter (Vertreternummer); wenn keine Vertreter-Auswahl gewünscht ist, muss "" angegeben werden

 

Ø  Datum von (Datum in ")

Hinterlegung bzw. Verweis auf den auszuwertenden von Zeitraum; wenn keine von Datumsangabe gewünscht ist, muss "" angegeben werden

Hinweis

Neben der Angabe des vollständigen Datums (z.B. "04.09.2024") wird auch eine Teilangabe unterstützt.

 

ü  "4" =             4. Tag des aktuellen Monats (lt. Einlogdatum)

ü  "5.7." =        05.07.<aktuelles Jahr> (lt. Einlogdatum)

ü  "3.6.12" =    03.06.2012

 

Ø  Datum von (Datum in ")

Hinterlegung bzw. Verweis auf den auszuwertenden von Zeitraum; wenn keine bis Datumsangabe gewünscht ist, muss "" angegeben werden

Hinweis

Neben der Angabe des vollständigen Datums (z.B. "06.09.2024") wird auch eine Teilangabe unterstützt.

 

ü  "9" =             9. Tag des aktuellen Monats (lt. Einlogdatum)

ü  "30.7." =      30.07.<aktuelles Jahr> (lt. Einlogdatum)

ü  "10.5.25" =  10.05.2025

 

Ø  Wert (0 / 1 / 2 / 3)

Angabe, ob der Verkaufs- oder Einkaufspreis ermittelt werden soll:

 

ü  0 - Umsatz (Betrag)

ü  1 - Rohertrag

ü  2 - Menge1

ü  3 - Menge2

 

Ø  Verkauf/Einkauf (0 / 1)

Angabe, ob der Verkaufs- oder Einkaufswert ermittelt werden soll:

 

ü  0 - Verkauf (Standard)

ü  1 - Einkauf

Hinweis

Bei Angabe eines Personenkontos wird der Parameter automatisch auf den Typ des Kontos korrigiert.

 

Beispiele

ü  =SALESSUMEXT ("", "230B005", -1, "", 0, "", "", 0, 0)
Die Funktion ermittelt für das Personenkonto "230B005" den gesamten bisherigen Umsatz (0). Alle weiteren Selektions-Parameter wurden nicht angegeben ("", -1 und 0).

 

ü  =SALESSUMEXT("10005", "", -1, "", 0, "01.01", "31.12", 1, 0)
Die Funktion ermittelt den Rohertrag (1) des Verkaufs (0) für den Artikels "10005" in dem Zeitraum "01.01" (Jahr aus Einlogdatum) bis "31.12" (Jahr aus Einlogdatum). Alle weiteren Selektions-Parameter wurden nicht angegeben ("", -1 und 0).

 

ü  =SALESSUMEXT("", "", 7, "", 0, "01.01.2024", "31.03.2024", 2, 1)
Die Funktion ermittelt die eingekaufte (1) Menge (2) der Artikelgruppe 7 für den Zeitraum "01.01.2024" bis "31.03.2024". Alle weiteren Selektions-Parameter wurden nicht angegeben ("" und 0).
