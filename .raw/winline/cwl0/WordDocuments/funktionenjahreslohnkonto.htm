Funktionen Jahreslohnkonto

 

Die nachfolgenden Funktionen haben alle eine ähnliche Bedeutung und die gleiche Syntax: alle Funktionen greifen auf die Werte des Jahreslohnkontos zu . Daher werden sie nicht im Detail, sondern nur Übersichtsweise beschrieben:

 

Syntax

Variable = Funktion (Monat, Jahr, Originalwerte)

Für Monat kann der gewünschte Monat eingegeben werden, bei Verwendung von 0 werden alle abgerechneten Monate des Abrechnungsjahres genommen.

Originalwerte ist ein optionaler Parameter, der standardmäßig auf 0 gesetzt ist (wodurch dann die letztgültigen Werte genommen werden). Wird der Wert auf 1 gesetzt, so werden die Originalwerte (die Werte, die bei der ursprünglichen Rechnung verwendet wurden) herangezogen.

GetKUGBezug()

Diese Funktion ermittelt den Bezug für die tatsächlich geleistete Arbeitszeit gemäß Einstellungen in den Betriebsdaten

GetKUGAusgleich()

Diese Funktion ermittelt den Bezug für die Vergütungsentschädigung, wobei sowohl der Unterstützungsprozentsatz als auch die AMS-Förderung berücksichtigt wird.

GetKUGDifferenz()

Mit dieser Funktion kann die Differenz zwischen dem tatsächlichen Bezug, der Vergütungsentschädigung und dem letzten Vollen Bezug berechnen.

GetKUGPauschalsatzbetrag ()

Mit dieser Funktion kann der Betrag ermittelt werden, der dem AN gemäß den Einstellungen mindestens als Verfügungsentschädigung zusteht, wobei dieser Betrag mit der Anzahl der Reduzierungsstunden hochgerechnet wird.

GetKUGPauschalsatz (Stunden, Bezug)

Mit dieser Funktion wird der pro Ausfallstunde festgelegte Pauschalsatz ermittelt. Optional kann als Parameter die Arbeitszeit des AN oder der Bezug, anhand dessen der Pauschalsatz ermittelt werden soll, angegeben werden. Dies wird vor allen dann benötigt, wenn der AN nur Teilzeitbeschäftigt ist. Damit kann dann der Bezug auf "Vollbeschäftigung" hochgerechnet werden. Wenn die "Normalstundenanzahl" verwendet werden soll, so kann der Wert 0 Übergeben werden.

 

Beispiel: Satz = GetKUGPauschalsatz (GetViewVar(400,116)/100)

 

In der Variable 400,116 sind die Anzahl der Beschäftigungsstunden pro Woche gespeichert, wobei dieser Wert ohne Nachkommastellen und 4stellig gespeichert wird. Dieser Wert wird dann auf die Anzahl der Wochenstunden, die im KUG-Stamm hinterlegt sind, hochgerechnet.

 

Beispiel: Satz = GetKUGPauschalsatz (0, 2400)

In diesem Beispiel der Pauschalsatz auf Basis des Wertes von 2400 in der entsprechenden Arbeitszeittabelle (Anzahl der Stunden, die im KUG-Stamm hinterlegt sind) ermittelt.

GetKUGLastBezug ()

Mit dieser Funktion kann der letzte Bezug anhand der Einstellungen im KUG-Stamm ermittelt werden, wobei allerdings die anteilige Sonderzahlung (1/6) noch nicht berücksichtigt ist. Damit können dann ggf. individuelle Berechnungen für den Einstiegswerte in die Pauschalsatztabelle ermittelt werden (wenn z.B. Einmalzahlungen berücksichtigt werden müssen).

GetJLKBeitragsgruppe (Monat, Jahr, Originalwerte)

Mit dieser Funktion wird die Beitragsgruppe aus der Abrechnung ausgelesen.
