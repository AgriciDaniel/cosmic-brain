Cockpit Definition - HTML

 

Das Element "HTML" ermöglicht es selbst definierte HTML-Elemente in das Cockpit zu integrieren.

Hinweis

HTML-Elemente werden im Cockpit unter einer eigenen Überschrift angezeigt.

 

 

Die folgenden Einstellungen können vorgenommen werden:

 

Ø  Bezeichnung

An dieser Stelle erfolgt die Eingabe der Bezeichnung, welche in weiterer Folge im Cockpit angezeigt werden soll.

 

Ø  HTML-Code

In dem Eingabefeld "HTML-Code" wird der HTML-Code hinterlegt.
