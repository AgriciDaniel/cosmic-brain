Projektstamm - Register "Stamm"

 

Im Register "Stamm" können die wichtigsten Daten zu dem Projekt erfasst werden.

 

 

Ø  Projektnummer

An dieser Stelle erfolgt die Eingabe der Projektnummer (20stellig alphanumerisch).

Hinweis

Über die Belegart-Option "0 - als Projekt speichern" (WinLine FAKT - Stammdaten - Belegstammdaten - Belegarten - Register "Stamm" - Einstellung "Projektnummer") kann definiert werden, ob bei der Erzeugung eines Belegs ein Projekt automatisch angelegt werden soll.

 

Ø  Bezeichnung 1 / Bezeichnung 2

An dieser Stelle kann die Bezeichnung bzw. Beschreibung zu diesem Projekt hinterlegt werden (jeweils 50stellig).

Hinweis

Wenn Projekte bei Belegerzeugung automatisch angelegt werden sollen, dann werden die Felder wie folgt gefüllt:

 

ü  Feld "Text1" im Register "Text" der Belegerfassung ist leer
Das Feld "Bezeichnung1" wird mit "Kontoname/Belegnummer" gefüllt.

 

ü  Feld "Text1" im Register "Text" der Belegerfassung ist gefüllt
Das Feld "Bezeichnung1" wird mit dem Inhalt von "Text1" versehen. Die Bezeichnung 2 wird mit "Kontoname/Belegnummer" gefüllt.

 

Ø  Projektgruppe

Über die Projektgruppe, welche an dieser Stelle hinterlegt wird, können verschiedene Projekte zusammengefasst werden, wobei in weiterer Folge die Auswertung auch nach Projektgruppen durchgeführt werden kann.

 

Ø  Verantwortlicher

An dieser Stelle kann der projektverantwortliche Mitarbeiter (WinLine Benutzer) hinterlegt werden.

 

Ø  Vertreter

In das Feld "Vertreter" kann der zuständige WinLine FAKT Vertreter hinterlegt werden.

 

Ø  Projektart

Aus der Auswahlbox kann die Art des Projekts definiert werden.

 

ü  1 - Verkaufschance
Bei der Auswahl "Verkaufschance" kann die dazugehörige Kunden- oder Lieferantenummer in das Feld "Kundennummer" eingetragen werden. In der Regel ist ein Projekt solange eine Verkaufschance, bis ein Auftrag / Bestellung existiert.

 

ü  2 - Kundenprojekte
Bei der Auswahl "2 - Kundenprojekt" kann wird die dazugehörige Kunden- oder Lieferantenummer in das Feld "Kundennummer" eingetragen werden. Sobald Belege mit der Stufe "Auftrag" / "Bestellung" existieren, ist ein Projekt in der Regel ein Kundenprojekt.

 

ü  3 - Serviceprojekt
Bei der Auswahl "3 - Serviceprojekt" können dem Projekt Artikel zugeordnet werden (siehe Button "Artikel einfügen"). D.h. das Projekt dient zur Überwachung / Zusammenfassung von Wartungsartikeln (Artikel für welche ein Service durchgeführt wird).

 

Ø  Service- / Wartungsartikel bearbeiten

Bei Serviceprojekten können mit Hilfe dieses Buttons die zugehörigen Wartungsartikel (Artikel für welche ein Service durchgeführt wird) erfasst werden.

Hinweis

Es stehen nur jene Artikel zur Verfügung, die im Artikelstamm (Register "Lager" - Unterregister "Einstellungen") das Kennzeichen für Serviceprojekt auf "1 - eröffnen" gestellt haben.

 

Ø  Kundennummer

In diesem Feld wird das Personenkonto des Projekts hinterlegt.

 

Ø  Kostenträger

An dieser Stelle besteht die Möglichkeit einen Kostenträger zu Informationszwecken zu hinterlegen Wird die Checkbox "erforderlich" aktiviert, so ist eine manuelle Übersteuerung der Kostenträgernummer nicht möglich.

Hinweis

Die Funktion der Checkbox wird derzeit nicht unterstützt.

 

Ø  Inaktiv seit

Das gesamte Projekt kann durch Aktivierung der Checkbox "Inaktiv seit" inaktiv gesetzt werden und steht somit für die Projekterfassung nicht mehr zur Verfügung

 

Ø  Beginnt

An dieser Stelle kann das Datum des Projektbeginns hinterlegt werden.

 

Ø  Ende Pre-Sales

In dieses Feld wird das Datum vom Ende der Pre-Sales-Phase hinterlegt.

 

Ø  Ende Post-Sales

In dieses Feld wird das Datum vom Ende der Post-Sales-Phase hinterlegt.
