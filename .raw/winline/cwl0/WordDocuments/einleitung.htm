Einleitung

 

In der WinLine ist die VB-Script-Engine eingebaut, die in verschiedenen Teilbereichen unterschiedliche Funktionen ausführen kann:

 

ü  WinLine FIBU
Formelsprache für das Berechnen von Beträgen in Buchungsarten.

 

ü  WinLine FAKT
Formelsprache für die Abarbeitung von Formeln in Zusammenhang mit Artikelgruppen (Frachtkostenberechnung, Transportversicherung etc. - ist im Standard möglich).

 

ü  WinLine LOHN
Formelsprache für die Abarbeitung von Lohnarten (ist im Standard möglich).

 

ü  WinLine ANBU
Formelsprache für die Berechnung der Staffel-AfA

 

ü  Makros
Aufzeichnen und Abspielen von immer wieder kehrenden Ereignissen (durchführen von Abschlussarbeiten, Datensicherung etc. - ist im Standard möglich)

 

ü  Fenster Makros
Aufzeichnungen, welche über den Button "Voreinstellungen speichern" gebildet werden.

 

ü  Fenster Skripte
Aktionen, die an ein bestimmtes Fenster und dort an ein bestimmtes Ereignis (Anklicken eines Buttons) geknüpft sind - nur mit eigener Lizenz möglich.

 

ü  System Skripte
Programmaufrufe oder Ereignisse können unabhängig vom gerade aktiven Fenster ausgeführt werden (WinLine - unabhängige Auswertungen etc. - nur mit eigener Lizenz möglich).

 

Hinweis

Damit man unter Windows die Scripts bearbeiten kann, muss eine Registrierung der sogenannten "Typelib" erfolgt sein. Sollte die WinLine dieses nicht automatisch durchführen können, so kann dieses mit fehlenden Windows-Recht zusammenhängen. In solch einem Fall sollte wie folgt vorgegangen werden:

 

ü  Zunächst eine Verknüpfung / Shortcut der "cwlstart.exe" mit dem Startparameter -RegisterTypelib anlegen

ü  Diese Verknüpfung / Shortcut über die rechte Maustaste mit "als Administrator ausführen" starten
