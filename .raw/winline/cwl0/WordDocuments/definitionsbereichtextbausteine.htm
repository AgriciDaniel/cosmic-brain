Definitionsbereich - Textbausteine

 

In dem Bereich "Textbausteine" können Textbausteine sowie Textbausteingruppen angeben werden, welche für den Mailversand verwendet werden sollen.

 

 

Ø  Kopfzeile

In der Kopfzeile des Bereichs wird die Bezeichnung "Textbausteine" angezeigt.

Achtung

Handelt es sich um einen Workflow-, End- oder Nebenschritt, welcher von einem Musterschritt abgeleitet wurde, so wird diese Verbindung ebenfalls in der Kopfzeile dargestellt.

 

 

Ø  Menü

Durch Anwahl des Menüs werden, abhängig vom aktuell gewählten Workflow-Objekt, weitere Funktionen zur Verfügung gestellt:

 

ü  Entsperren / Sperren
Handelt es sich um einen Workflow-, End- oder Nebenschritt, welcher von einem Musterschritt abgeleitet wurde, so kann hier definiert werden, ob die Feldinhalte fix vom Musterschritt kommen oder editierbar sein sollen.

 

ü  Maximieren / Minimieren
Bei einem Maximieren werden die Textbausteine als einziger Bereich in der Definition angezeigt, bzw. bei einem Minimieren wieder alle Bereiche in der Definition.

 

Ø  Intern / Extern

Beim Mailversand des WinLine CRMs wird zwischen Mails an externe und interne Benutzer unterschieden.

 

ü  Externe Benutzer
Externe Benutzer sind grundsätzlich WinLine Benutzer der Benutzergruppen "10 - Surfer", "11 - Interessenten" und "12 - Debitoren". Zusätzlich fallen alle Empfänger hierunten, die keine WinLine Benutzer sind.

 

ü  Interne Benutzer
Interne Benutzer sind alle Benutzer aller restlichen (nicht externen) Benutzergruppen.

 

Bestehende Textbausteine können über die Autovervollständigung oder den Matchcode gesucht und ausgewählt werden. Zum gewählten Textbaustein wird die entsprechende Textbausteinnummer in Klammern neben dem Namen des Eingabefelds angezeigt.

 

Ø  Textbausteingruppe

In diesem Feld kann eine Textbausteingruppe hinterlegt werden. Damit können in weiterer Folge - wenn für den Schritt die Folgeaktion "82 - Mailversand an PAB" verwendet wird und das Feld "Extern" gefüllt wurde - im Postausgangsbuch alternative Texte dieser Textbausteingruppe ausgewählt werden.
