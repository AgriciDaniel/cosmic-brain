Schritt 5: Numerische Variablen einfügen

 

Als nächsten Schritt fügen wir eine zusätzliche Variable in das Formular ein und platzieren Sie in der Artikelzeile.

Öffnen Sie das Fenster "Numerischer Wert" entweder mit den Menüeinträgen

1  Neues Element

1  Num. Variable

oder mit dem entsprechenden Button

1  numerische Variable

 

Im nun geöffneten Fenster wählen Sie aus der Spalte

Ø  Views    026 BestelldatMitte

und aus der Spalte

Ø  Vars       0012 Artikelgruppe

die Variable für die Artikelgruppe aus und positionieren sie in der Artikelzeile. Wichtig ist, dass Sie der Variable das Flag N zuweisen. Dazu gehen Sie wie folgt vor:

Markieren Sie die Variable und tragen Sie in der Formatierungsleiste im Eingabefeld

Ø  Flags

den Buchstaben

Ø  N

ein. Damit wird diese Variable im Mittelteil / Artikelzeile angedruckt.
