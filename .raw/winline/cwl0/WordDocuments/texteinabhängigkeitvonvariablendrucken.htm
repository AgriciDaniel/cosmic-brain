Texte in Abhängigkeit von Variablen drucken

 

Anforderung

Welche Möglichkeiten gibt es, in einem Formular Variablen und/oder Texte - wenn sie nicht ausgefüllt sind - am Ausdruck unsichtbar zu machen?

 

Beispiel

Auf einer Auftragsbestätigung soll "Angebot vom Datum" angedruckt werden, wenn die Variable ausgefüllt ist, d.h. wenn es vorher ein Angebot gegeben hat. Wenn nicht, dann sollte die gesamte Zeile nicht angedruckt werden.

 

Lösung

Das kann mit folgender Formel im Formular Editor gelöst werden (wobei die Variable 0/50 das Angebotsdatum darstellt):

 

If IsNull (Value (0,50)) Then

result = ""

Else

result = "Angebot vom: "&Value(0,50)

End If

ResultValue = result

Hinweis

Der Resultattyp sollte auf "Text" gestellt werden,
