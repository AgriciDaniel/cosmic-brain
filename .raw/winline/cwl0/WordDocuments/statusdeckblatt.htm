Status Deckblatt

 

Ein Deckblatt kann unterschiedliche Stati haben. Der aktuelle Status wird immer unter "Allgemein" angezeigt.

 

 

Um den Status zu ändern, muss auf "weitere Aktionen" geklickt werden. Es kann aus allen verfügbaren Stati gewählt werden. Jeder Status ist ein Workflow Schritt.

Hinweis

Über den Workfloweditor können zusätzliche Stati zur Verfügung gestellt werden, bzw. die bestehenden bei Bedarf angepasst werden.
