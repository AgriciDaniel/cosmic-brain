Kontrakterfassung - Register "Mitte"

 

In dem Register "Mitte" können die Kontraktzeilen erfasst bzw. editiert werden. Um was für eine Kontraktzeile es sich handelt wird dabei über die Spalte "Typ" definiert.

Hinweis

Weitere Informationen, u.a. zu den Buttons des Programms "Kontrakterfassung", sind dem Kapitel Kontrakterfassung zu entnehmen.

 

 

Folgende Eingabefelder, Einstellungen und Information stehen zur Verfügung:

 

Kontraktdaten

 

Ø  Kontonummer / Gruppennr.

An dieser Stelle wird die Nummer des Hauptkontos (WinLine START - Parameter - FAKT-Parameter - Belege - Allgemein - Option "Hauptkonto für Belege") bzw. der Gruppe des aktuellen Kontrakts angezeigt.

 

Ø  Name

An dieser Stelle wird der Kontoname der Kontonummer bzw. der Gruppe dargestellt und das Fenster Kontoinformation kann direkt geöffnet werden.

 

Ø  Kontraktnummer

An dieser Stelle wird die Kontraktnummer des Kontrakts angezeigt.

 

Ø  Kontraktdatum

Hier wird das Kontraktdatum des Kontrakts dargestellt.

 

Ø  allg. Laufzeit von / bis

In diesen Feldern wird die allgemeine Laufzeit des Kontrakts dargestellt.

 

Belegzeilen

 

Ø  Anzahl

An dieser Stelle wird die Gesamtanzahl der Kontraktzeilen aufgeführt und angegeben, in welcher Zeile sich befunden wird.

 

Ø  Preisliste

An dieser Stelle wird die Preisliste der Kontraktzeilen angezeigt. Eine Änderung ist nur im Register Zusatz möglich.

 

Ø  Gesamtnettobetrag / Gesamtbruttobetrag

Durch Aktivierung der Option "Gesamtbetrag" (Register Optionen) werden die mitlaufenden Informationsfelder "Gesamtnettobetrag" und "Gesamtbruttobetrag" angezeigt.

 

Tabelle "Kontraktzeilen"

 

In der Tabelle werden die Zeilen des Kontrakts erfasst. Hierbei ist die Erfassung an die normale Belegerfassung angelehnt (nähere Information entnehmen Sie bitte dem Kapitel Belegerfassen - Register "Mitte").

Hinweis

Neben den direkt angezeigten Spalten stehen viele optionalen Spalten zur Verfügung. Dieses können über das Kontextmenü der rechten Maustaste (Funktion "Spalten anzeigen/verstecken") in die Tabelle eingebunden werden.

Achtung

Nur die Spalten "Artikel", Menge", Preis", "Rab1%", "Rab2%", "Colli", "Laufzeit", "Ersatzartikelnummer" und "Ersatzartikelbezeichnung" haben eine direkte Auswirkung auf den Kontraktpreis und werden auch so in die Preistabelle des Artikelstamms übergeben. Weitere Spezialeinstellungen (Provisionscode, Losgröße, Kontraktabschluss, etc.) können im Register Detailinfo getätigt werden.

Alle weiteren Hinterlegungen werden bei einer Kontraktabnahme nur verwendet, wenn das Programm Kontrakte abbuchen verwendet wird.

 

Tabelle "Artikelinfo"

 

Wird ein Artikel erfasst, so werden in der Tabelle "Artikelinfo" u.a. der Einstandspreis, der Bewertungspreis und der aktuelle Lagerstand des Artikels angezeigt. Handelt es sich um einen Handelsstücklistenartikel, bei welchem das Stücklistenfenster geöffnet werden darf, so wird neben dem Artikeltyp des Icon  angezeigt. Per Doppelklick auf dieses wird das Stücklistenfenster geöffnet.
