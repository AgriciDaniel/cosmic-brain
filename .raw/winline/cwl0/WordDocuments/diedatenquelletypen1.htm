Die Datenquelle - Typen

 

Jede Datenquelle beinhaltet die Daten einer spezifischen Auswertung, wobei nach den folgenden Typen unterschieden wird:

 

ü  Temporäre Datenquelle (Snapshot)

ü  Snapshot

ü  View

ü  MasterView

 

Temporäre Datenquelle (Snapshot)

Eine temporäre Datenquelle (Snapshot) wird von der WinLine immer dann erzeugt, wenn eine Datenquelle benötigt wird (z.B. bei der Ausgabe eines Power Reports), aber ohne Angabe einer Datenquelle gearbeitet werden soll (Datenquellen-Button auf "keine Datenquelle").

Ein solcher Snapshot ist immer "privat", wird von der WinLine mit einer festen (internen) Betitelung versehen und steht im Datenquellen - Matchcode oder der Datenquellenverwaltung nicht zur Verfügung.

 

Snapshot

Ein Snapshot ist eine Momentaufnahme von Daten, die bei Bedarf über den "Datenquellen"-Button wieder abgerufen werden kann. Zur Unterscheidung unterschiedlicher Snapshots kann bei der Erstellung eine individuelle Betitelung vergeben werden:

 

ü  Benutzer (automatisch)

ü  Mandant (automatisch)

ü  Filter (automatisch)

ü  Selektion 1 - Textfeld (manuelle Eingabe)

ü  Selektion 2 - Textfeld (manuelle Eingabe)

ü  Selektion 3 - Zahlenfeld (manuelle Eingabe)

ü  Selektion 4 - Zahlenfeld (manuelle Eingabe)

 

View

Eine View  ist eine aktuelle Sicht auf die Daten. D.h. die Daten der Ausgabe sind immer "live". Da bei der Verwendung von Views keine Berechtigungsprofile oder Konteneinschränkungen über die Vertreterzuordnung berücksichtigt werden, können nur Volladministratoren oder Benutzer mit dem Teiladministrationsrecht "Datenadministration" diese erzeugen. Die Erstellung von Views steht in den folgenden Programmbereichen zur Verfügung:

 

ü  WinLine LIST
Es können Views für diverse Listen (Ausnahme "20 - Adressbuch" und "29 - Datenquellen") erzeugt werden. Wichtig ist hierbei nur, dass im Aufbau keine "Lokalen Variablen", "Eigenschaften", "FIBU-Salden" und "Formeln" enthalten sein dürfen.

Hinweis

Wird bei der Liste mit einem Filter gearbeitet, so wird die Selektion des Filters ohne Sortierung ebenfalls in die View übertragen.

 

ü  Enterprise Cubes
Es können Views für Cubes des Typs "Verkaufsanalyse" und "Finanzanalyse" erzeugt werden. Wichtig ist hierbei nur, dass im Aufbau keine Eigenschaften enthalten sein dürfen.

 

MasterView

MasterViews  sind eine aktuelle Sicht auf mehrere Snapshots und / oder Views. Die Daten der Ausgabe sind so aktuell, wie die zu Grunde liegenden Datenquellen.

Die Erstellung und Anpassung von MasterViews findet über das Programm Datenquellen - MasterView statt. Eine Aktualisierung der MasterView im klassischen Sinne findet nicht statt, da es sich "nur" um eine Sicht auf bereits bestehende Datenquellen handelt.
