Die ersten Schritte in der APP unter Android

 

Unter Android wird die Info-Seite ausgegeben.

 

 

Um die Vollversion aus einem externen Netzwerk auf zu rufen, können Sie den Pfad zu Ihrem WinLine Server jederzeit in den Einstellungen ändern.

 

 

 

Unter WinLine mobile URL kann der jeweilige Pfad zum WinLine Server mit dem Zusatz "/WinLine mobile" hinterlegt werden.

Beispiel:

http://192.168.XXX.XXX:82/MWL
