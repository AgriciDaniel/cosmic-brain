Inventur - Optionen / Inventur - Übernahme Soll => Ist / Inventur - Übernahme 0 => Ist

 

Mit Hilfe dieses Inventur-Fensters können, abhängig vom zuvor gewählten Button, folgenden Arbeiten durchgeführt werden:

 

ü  Button Optionen (Programm "Inventur", Register Eingabe)
Es können u.a. nicht gebuchte Inventurerfassungen initialisiert oder bereits gebuchte Erfassungen reaktiviert werden.

 

ü  Button Übernahme Soll => Ist (Programm Inventur - Erfassung)
Alle Datensätze der Inventurerfassung werden mit einem editierbaren Erfassungsvorschlag versehen, wobei sich die Inventurmenge über den Sollstand des jeweiligen Artikels ermittelt. Die hierfür benötigten Angaben werden im Fenster "Inventur - Übernahme Soll => Ist" hinterlegt.

 

ü  Button Übernahme 0 => Ist (Programm Inventur - Erfassung)
Alle Datensätze der Inventurerfassung werden mit einem editierbaren Erfassungsvorschlag versehen, wobei die Inventurmenge 0 lautet. Die hierfür benötigten Angaben werden im Fenster "Inventur - Übernahme 0 => Ist" hinterlegt.

 

Das Fenster wird je nach zu tätigender Arbeit unterschiedlich dargestellt und in den nachfolgenden Kapiteln detailliert beschrieben.
