Benutzerwechsel

 

Im Menüpunkt…

 

1  WinLine START

1  Datei

1  Benutzerwechsel

 

… kann die WinLine für weitere Eingaben gesperrt werden.

 

 

Im Feld Benutzer wird automatisch der gerade angemeldete Benutzer angezeigt. Wenn das Password dieses Benutzers eingegeben wird, wird die WinLine wieder entsperrt und es kann wie gewohnt weitergearbeitet werden.

Wenn aber ein Benutzername und das Passwort eines anderen Benutzers angegeben wird, wird ein Benutzerwechsel durchgeführt.

 

Hiebei werden alle Berechtigungen für den neu anzumeldenden Benutzer geladen. Zusätzlich wird in diesem Fenster ein Foto angezeigt, falls beim gewählten Benutzer in der Benutzeranlage ein Foto hinterlegt ist.

 

Achtung

Bei geöffneten Fenster "Belege erfassen" und/oder "Buchen (Dialog-Stapel)" kann kein Benutzerwechsel durchgeführt werden, da diese Fenster zuvor manuell geschlossen werden müssen.
