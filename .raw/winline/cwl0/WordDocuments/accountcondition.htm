AccountCondition

 

Funktion

Diese Funktion dient dazu, die Kopfdaten, die normalerweise aus dem Konto vorbelegt werden, zu belegen. Es können Summenrabatt, Zahlungskondition, Priorität, Vertreter, Steuerleiste, Tour, Gebiet, Zahlungskennzeichen und Teilliefersperre übersteuert werden. Dabei können folgende Werte (pos) belegt werden:

 

ü  ctVoucherdiscount          => Summenrabatt

ü  ctPartDelivery               => Teilliefersperre

ü  ctConditionExt                => Zahlungskondition - Bezeichnung

ü  ctCondition                    => Zahlungskondition - interne Nummer

ü  ctPriority                       => Priorität

ü  ctSalesRep                    => Vertreter

ü  ctTaxclass                     => Steuerleiste

ü  ctRoute                         => Tour

ü  ctAera                          => Gebiet

ü  ctPaymentcode              => Zahlungskennzeichen

Syntax

AccountCondition pos, Value

 

Beispiele

AccountCondition ctVoucherdiscount, "-2.0"

Der Summenrabatt wird mit -2 % belegt.

 

AccountCondition ctConditionExt, "Endkunden"

Als Kondition wird Endkunden verwendet.

 

AccountCondition ctCondition, Value (50,107)

Es wird die Kondition aus dem Kontenstamm verwendet.

 

Achtung

Die Änderungen wirken solange, bis entweder ein Parameter manuell im Programm geändert wird (z.B. die Zahlungskondition im Reiter Zusatz neu eingegeben wird) oder eine andere Formel aufgerufen wird, die diese Parameter setzt.

Hinweis

Diese Funktion wird in der Belegformel nicht unterstützt.
