Externes Objekt (OIF)

 

Ø  Externes Objekt

Ein Externes Objekt (auch "OIF" genannt) ist ein Objektorientiertes Info Formular. Dieses Element wird immer als eigener Thread ausgeführt, wodurch die Abarbeitung immer Hintergrund stattfindet und das Ergebnis in einem eigenen Bereich dargestellt wird. Grundsätzlich sind mehrere Typen von OIF´s möglich:

 

ü  Text
Mit diesem Typ kann ein Text (reiner Text oder RTF) dargestellt werden. Der Text kommt entweder aus der Variable, die angegeben werden kann, oder es wird ein fixer Text im Feld "Text" hinterlegt. Dort können auch Ersetzungen in der Form <VAR:x/y> verwendet werden.

 

ü  Bitmap
Mit diesem Typ kann eine Grafik dargestellt werden. Der Name des Bildes kommt entweder aus einer Variable, oder aus dem Feld "Text".

 

ü  Spool-Preview
Mit diesem Typ kann der Inhalt einer SPL-Datei angezeigt. Der Name der SPL-Datei kommt entweder aus einer Variable oder wird direkt im Feld "Text" eingetragen.

 

ü  Browser
Dieser Typ stellt im Bereich des OIF einen Internetbrowser dar (den in Windows installierten Internet Explorer). Die Adresse, welche im Browser dargestellt wird, kommt entweder aus einer Variable oder wird direkt im Feld "Text" eingetragen. Der Browser wird mit Scrollbars dargestellt und kann wie der Internet Explorer bedient werden (z.B. wird beim Drücken der rechten Maustaste das Kontextmenü des Browsers dargestellt).

 

ü  Objekt
Mit dem Typ "Objekt" kann auf fest definierte Datenbereiche (Objekte) zugegriffen werden, wobei für jeden Datenbereich vorgefertigte Formulare mitgeliefert werden.

 

Hinweis

Welche Einstellungsmöglichkeiten im Fenster "Externes Objekt/OIF" vorhanden sind, ist abhängig vom ausgewählten Typ.
