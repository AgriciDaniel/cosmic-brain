Neuinstallation - WinLine Server

 

Im Zuge der Installation des WinLine Server wird als neues Unterverzeichnis des WinLine-Serververzeichnisses der Ordner "EWL" angelegt, welcher die erforderlichen Anwendungsdateien (exe-Dateien) sowie in weiterer Folge die Konfigurationsdatei "server.config" und div. andere Dateien enthält.

 

Achtung

Das WinLine-Verzeichnis am Server muss für die Einrichtung als Server-Installation mit allen Zugriffsberechtigungen freigegeben werden.

Weiters ist zu beachten dass ab Betriebssystem Windows Vista, z.B. zum Starten des  WinLine Server Dienstes im ADMIN der WinLine ADMIN als Administrator ausgeführt werden muss.
