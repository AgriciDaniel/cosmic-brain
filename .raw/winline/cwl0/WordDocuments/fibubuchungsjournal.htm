1  Auswertungen

1  FIBU Buchungsjournal

 

wird ein Buchungsjournal ausgegeben, welches die beim Anlagenverkauf und Anlagenabgang in die WinLine FIBU übergebenen und dort verbuchten Abgänge sowie die über die WinLine FIBU erfassten Zugänge auflistet.

 

 

Ø  Inventarnummer von - bis

In diesen Feldern kann nach den Inventarnummern eingeschränkt werden, welche in der Auswertung berücksichtigt werden sollen.

 

Ø  Subanlagen

Ist die Ausgabe des FIBU Buchungsjournals auf eine einzige Inventarnummer eingeschränkt, für welche Subanlagen existieren, kann hier zusätzlich auf die Subanlagen eingeschränkt werden.

 

Ø  Anlagengruppe von - bis

Die Anlagengruppe, der das Inventargut im Anlagenstamm zugeordnet wurde, kann in diesen Feldern eingeschränkt werden.

 

Ø  FIBU-Konto

Über die von / bis – Eingabe kann die Auswertung auf FIBU-Konten eingeschränkt werden.

 

Ø  Bereich

Hier kann entschieden werden, ob in dem FIBU Buchungsjournal die steuerrechtlichen oder handelsrechtlichen Werte ausgegeben werden sollen.

Automatisch vorgeschlagen wird das Abschreibungsverfahren, welches im ANBU-Parameter / Buchen für die Buchungsübergabe definiert ist.

 

Ø  Datum

Einschränkung des Zeitraumes, der ausgewertet werden soll.

 

Buttons

 

Ø  Ausgabe Bildschirm

Standardmäßig wird die Ausgabe auf dem Bildschirm vorgeschlagen, die auch durch Drücken der F5-Taste gestartet werden kann.

 

Ø  Ausgabe Drucker

Die Auswertung wird am Drucker ausgegeben.

 

Ø  Ende

Das Fenster wird geschlossen, ohne dass eine Auswertung ausgegeben wird.
