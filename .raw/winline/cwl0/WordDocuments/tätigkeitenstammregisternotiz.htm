Tätigkeitenstamm - Register "Notiz"

 

In dem Register "Notiz" kann eine zusätzliche Beschreibung zur Tätigkeit eingegeben werden.

 

 

Folgende Eingabefelder und Information stehen zur Verfügung:

 

Ø Notiz

An dieser Stelle kann eine Notiz / Beschreibung zu der Tätigkeit erfasst werden.

 

Ø Personenkonto

In diesem Feld kann ein Personenkonto (Kunde / Lieferant / Interessent) hinterlegt werden. Dieses Feld dient derzeit nur der Information und hat keine besondere Funktion. Über die Matchcode-Funktion kann nach allen Personenkonten gesucht werden.
