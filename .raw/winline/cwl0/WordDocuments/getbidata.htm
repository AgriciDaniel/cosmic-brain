GETBIDATA

 

Mit dieser Funktion können die Daten eines Datenquellen-Widgets des Typs Kachel, Grafik, Datentabelle, Tabelle, Olap und Tag Cloud ausgegeben werden. Die Auswahl des Widgets kann durch einen Klick auf dessen Kopfleiste erfolgen.

Hinweise

Bei Nutzung der Funktion ist folgendes zu beachten:

 

ü  Die GETBIDATA-Funktion reserviert sich auf Grundlage des Datenquellen-Widgets automatisch einen Darstellungsbereich. Sollten Zellen innerhalb dieses Bereichs bereits in Verwendung sein, so führt dieses zu der Meldung "#SPILL!".

ü  Da die angezeigten Daten dynamisch ermittelt werden, ist ein Formatieren innerhalb des Darstellungsbereichs nicht vorgesehen (u.a. Datenformat und Textformat).

ü  Das Datenfeld "Zeile" wird, ausgehend von dem Widget Tabelle, nicht in das WinCalc übertragen.

ü  Soll mit den Informationen der Funktion gearbeitet werden (z.B. Prozentberechnungen), so muss dieses innerhalb des gleichen Tabellenblatts stattfinden.

ü  Bei dem Verschieben von Zellen werden nur die Parameter der Funktion verschoben, aber der Datenzugriff nicht erneut ausgeführt. Dieser kann durch das Bearbeiten der Funktion via Funktion bearbeiten reaktiviert werden.

ü  Sollte die Anzahl der Zeilen bzw. Spalten für eine Anzeige im CalcSheet nicht ausreichen, so wird auf dieses hingewiesen. Sobald ausreichend Platz zur Verfügung steht, erfolgt die Anzeige.

 

Syntax

=GETBIDATA (WidgetID, Beschriftung, Anzahl Datensätze, Synchronisierung)

 

Ø  WidgetID (Eingabe in "")

Hinterlegung bzw. Verweis auf die ID des Widgets, welches ausgegeben werden soll

 

Ø  Beschriftung (Zahl)

Angabe, ob eine Beschriftungszeile ausgegeben werden soll:

 

ü  0 - ohne Beschriftung

ü  1 - mit Beschriftung (Standard)

 

Ø  Anzahl Datensätze (Zahl)

Hier kann die maximale Anzahl der Datensätze hinterlegt werden, welche im CalcSheet dargestellt werden sollen.

Achtung

Sollte die Anzahl der Zeilen bzw. Spalten für eine Anzeige im CalcSheet nicht ausreichen, so wird auf dieses entsprechend hingewiesen.

 

Ø  Synchronisierung (Zahl)

Definition, ob bei dem Auslösen eines Quickfilters die Daten im CalcSheet aktualisiert werden sollen:

 

ü  0 - keine Synchronisation

ü  1 - automatische Synchronisation (Standard)

 

Beispiele

ü  =GETBIDATA ("T2137#widget3", 1, 50, 1)
Die Funktion gibt die ersten 50 Datenätze des Widgets "3" aus Datenquelle "T2137" mit einer Überschrift (1) aus, wobei die Implementation im Power Report stattgefunden hat. Bei Nutzung des Quickfilters erfolgt eine Aktualisierung der Daten im CalcSheet (1).

 

ü  =GETBIDATA ("LIST_39388#87555dedf4824bcc954fa74f6d281b89", 0, 20, 1)
Die Funktion gibt die ersten 20 Datenätze des Widgets "87555dedf4824bcc954fa74f6d281b89" aus Datenquelle " LIST_39388" ohne eine Überschrift (0) aus, wobei die Implementation im Cockpit  stattgefunden hat. Da es im Cockpit keinen Quickfilter gibt, ist die Synchronisationseinstellung (1) irrelevant.
