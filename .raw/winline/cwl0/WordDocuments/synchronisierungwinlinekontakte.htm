Synchronisierung WinLine Kontakte

 

Wenn eine Exchange Verbindung angelegt ist, kannim WinLine Start unter

 

1  Optionen

1  Synchronisation

 

ein Abgleich der WinLine Kontakte mit dem Exchange Server durchgeführt werden.

 

Ø  Benutzerdaten für Exchange-Server

In dieser Auswahllistbox kann der jeweilige Exchange Server ausgewählt werden, welcher in den Einstellungen angelegt wurde.

 

Ø  Manuell hinzufügen

In diesem Feld kann ein WinLine-Kontakt manuell ausgewählt werden, welcher für den Exchange bzw. Abgleich berücksichtigt werden soll.

 

Ø  Filter

Wenn der Button rechts neben dem Feld "Filter" angewählt wird, kann entweder ein temporärer Filter oder ein bereits angelegter Filter ausgewählt werden. Die Selektionen in diesem Filter werden beim Füllen der darunterliegenden Tabelle berücksichtigt. Somit werden nur diese Datensätze für den Abgleich angezeigt.

 

Ø  Auch inaktive

Beim Aktivieren dieser Checkbox werden auch innerhalb der WinLine inaktiv gesetzte Kontakte angezeigt und beim Abgleich berücksichtigt.

 

Ø  Neue Kontakte anlegen

Falls diese Checkbox aktiviert ist, werden neue Kontakte in den darunterliegenden Tabellen angezeigt und somit beim Abgleich neu angelegt. Wenn diese Option nicht gesetzt ist, werden neue Kontakte (grün gehalten) nicht angezeigt und somit auch nicht innerhalb der WinLine angelegt.

 

Wenn die gewünschten Selektionen getroffen wurden, kann mittels "Exchange Kontakte anzeigen", "WinLine Kontakte anzeigen" oder "Vorschläge anzeigen" die jeweilige darunterliegende Tabelle mit den Datensätzen befüllt werden

 

Bei den WinLine Kontakten gibt es die Möglichkeit die Anzeige mit einem Filter, einem bestimmten Kontakt, auf die inaktiven Kontakten einzuschränken und zusätzlich die Option, ob neue Kontakte innerhalb der WinLine angelegt werden sollen oder nicht. So werden alle gewünschten Kontaktdaten aus dem WinLine Kontaktestamm und aus dem Exchange Kontaktestamm angezeigt.

 

Mit "Vorschläge anzeigen" werden alle Kontakte angezeigt und jene mit einem Häkchen hinterlegt, die synchronisiert werden können, weil sie entweder neu sind oder eine Änderung beinhalten.

 

Soll laut der hinterlegten Logik (unter WinLine START/Parameter/Einstellungen/Exchange) eine Änderung bei einem Kontakt vorgenommen werden, so wird der betroffene Kontakt "rot" dargestellt.

 

Wird ein Kontakt als neu erkannt wird dieser "grün" angezeigt.

 

 

Mit "Vorschläge durchführen" werden alle mit einem Häkchen hinterlegten Kontakte direkt synchronisiert.
