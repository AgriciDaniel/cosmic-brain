GETMERKLISTE

 

Mit dieser Funktion können die Daten (Stammdatenobjekte) einer Merkliste auf Grundlage eines Namens ausgegeben werden

Hinweise

Bei Nutzung der Funktion ist folgendes zu beachten:

 

ü  Die GETMERKLISTE-Funktion reserviert sich auf Grundlage des darzustellenden Merklisteninhalts automatisch einen Darstellungsbereich. Sollten Zellen innerhalb dieses Bereichs bereits in Verwendung sein, so führt dieses zu der Meldung "#SPILL!".

ü  Da die angezeigten Daten dynamisch ermittelt werden, ist ein Formatieren innerhalb des Darstellungsbereichs nicht vorgesehen (u.a. Datenformat und Textformat).

ü  Soll mit den Informationen der Funktion gearbeitet werden (z.B. Ermittlung der Bezeichnung oder Ausgabe von statistischen Werten), so müssen die Daten zuvor festgeschrieben werden!

ü  Sollte die Anzahl der Zeilen bzw. Spalten für eine Anzeige im CalcSheet nicht ausreichen, so wird auf dieses hingewiesen. Sobald ausreichend Platz zur Verfügung steht, erfolgt die Anzeige.

 

Syntax

=GETMERKLISTE (Merkliste, Anzahl Datensätze, Objekt, Objekt-Typ anzeigen [optional])

 

Ø  Merkliste (Eingabe in "")

Hinterlegung bzw. Verweis auf den Namen jener Merkliste, deren Daten ausgegeben werden sollen

 

Ø  Anzahl Datensätze (Zahl)

Hier kann die maximale Anzahl der Datensätze hinterlegt werden, welche im CalcSheet dargestellt werden sollen.

Achtung

Sollte die Anzahl der Zeilen bzw. Spalten für eine Anzeige im CalcSheet nicht ausreichen, so wird auf dieses entsprechend hingewiesen.

 

Ø  Objekt (0 / 1 / 2 / 3…)

Angabe, welche Stammdatenobjekte ausgegeben werden sollen:

 

ü  0 - alle Objekte

ü  1 - Personenkonto

ü  2 - Interessent

ü  3 - Ansprechpartner

ü  4 - Kontakt

ü  5 - Vertreter

ü  7 - Arbeitnehmer/Mitarbeiter

ü  8 - Artikel

ü  9 - Projekt

ü  10 - CRM

ü  11 - Sonstige Konten

ü  12 - Benutzer

 

Ø  Objekt-Typ anzeigen (0 / 1 / 2) [optional]

Optionale Angabe, ob der Typ des Objekts ausgewiesen werden soll:

 

ü  0 - keine Anzeige (Standard)

ü  1 - Nummer anzeigen

ü  2 - Bezeichnung anzeigen

 

Beispiele

ü  =GETMERKLISTE ("Präsentation", 50, 3)
Die Funktion gibt die ersten 50 Datenätze der Merkliste "Präsentation" aus, wobei nur Ansprechpartner (3) berücksichtigt werden sollen.

 

ü  =GETMERKLISTE ("Kunden", 25, 0, 2)
Die Funktion gibt die ersten 25 Datenätze der Merkliste "Kunden" aus, wobei alle Objekte (0) berücksichtigt werden sollen. Zur Kontrolle wird hierbei auch der Objekt-Typ als Klartext (2) ausgegeben.
