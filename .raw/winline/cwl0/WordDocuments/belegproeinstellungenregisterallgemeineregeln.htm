Beleg Pro - Einstellungen - Register "allgemeine Regeln"

 

In der Tabelle "Regeln" des Registers "allgemeine Regeln" können spezifische Regeln für das Füllen der Buchungs- bzw. Belegvariablen hinterlegt werden, falls die programminterne Logik beispielsweise den Gesamtwert nicht automatisch erkennen kann.

Hinweise

ü  Gültigkeit
Die eingetragenen Regeln wirken global und werden somit bei jedem Buchungs- bzw. Belegeingang verwendet, je nachdem, bei welchen Verarbeitungstyp die Regeln hinterlegt wurden.

 

ü  Leereintrag
Damit ein Leereintrag hinzugefügt wird, muss die Variable ausgewählt und die Checkbox "Vorb. verwenden" aktiviert werden. Diese Variable wird beim Import dann immer direkt als Leereintrag in der Tabelle angezeigt.

 

ü  Beleg Pro - Vorlage
Wenn die gleichen Variablen innerhalb einer verwendeten "Beleg Pro - Vorlage" definiert sind, werden die Werte/Regeln aus der verwendeten "Beleg Pro - Vorlage" herangezogen.

Folgende Eingabefelder und Einstellungen stehen zur Verfügung:

 

Beleg / Buchung

 

Ø  Verarbeitungstyp

An dieser Stelle erfolgt die Definition, ob Regeln für Belege oder Buchungssätze hinterlegt werden sollen.

 

ü  0 - Buchungs-Import
Bei diesem Eintrag wirken die in der Tabelle eingetragenen Regeln nur dann, wenn es sich beim Eingang über das Modul "Beleg Pro" um eine Buchungserstellung (WinLine FIBU) handelt.

 

ü  1 - Batchbeleg
Bei diesem Eintrag wirken die in der Tabelle eingetragenen Regeln nur dann, wenn es sich beim Eingang über das Modul "Beleg Pro" um eine Belegerstellung (WinLine FAKT) handelt.

 

Tabelle "Regeln"

 

Folgende Spalten stehen zur Verfügung:

 

Ø  Feldauswahl

Hier stehen alle Buchungs- bzw. Belegvariablen zur Auswahl, welche anhand der Regel befüllt werden soll. Durch Auswahl des Eintrags "999999 *** Matchcode öffnen ***" wird ein Matchcode geöffnet, über welchen nach der gewünschten Variable gesucht werden kann.

 

Ø  Vorlauftext

Im Vorlauftext muss der Text bzw. Wert eingeben werden, welcher vor dem Wert steht, welcher in die Variable befüllt werden soll. (Siehe Beispiel)

 

Ø  Maskierung

In der Maskierung muss anschließend der zu übernehmende Wert bzw. seine Definition bestimmt werden, die sozusagen als Ersatzzeichen gelten.

 

#          = Buchstaben und Zahlen (Es werden Zahlen und Buchstaben übernommen)

?          = Zahlen (Es werden nur Zahlen übernommen)

_          = jedes beliebiges Ziechen (Es wird alles übernommen)

 

Wenn eine Maskierung mit fünf Unterstrichen definiert wird, werden die nächsten fünf Werte, unabhängig davon ob es eine Zahl oder Buchstabe ist, in das definierte Feld übernommen, wenn der hinterlegte Vorlauftext zutrifft.

 

Ø  Vor. verwenden / Vorbelegung

Es kann auch eine Vorbelegung für dieses Feld anhand einer Regel definiert werden.

 

Tabellenbuttons

 

Ø  Regel entfernen

Durch Auswahl dieses Buttons wird die markierte Regeln gelöscht.

 

Ø  Zeile nach oben / Zeile nach unten

Mit diesen Buttons können Regeln innerhalb der Tabelle verschoben werden.

 

Ø  Ausgabe Excel

Durch Anwahl des Buttons "Ausgabe Excel" wird der Inhalt der Tabelle an Microsoft Excel übergeben.

 

Ø  Tabelleneinstellungen speichern

Die Spalten einer Tabelle können grundsätzlich an beliebige Positionen verschoben, bzw. in der Breite entsprechend angepasst werden. Durch Anwahl des Buttons "Tabelleneinstellungen speichern" werden die Einstellungen benutzerspezifisch gespeichert und bei dem nächsten Aufruf des Programmpunktes wieder vorgeschlagen.

 

Ø  Gesamteinstellungen speichern

Im Gegensatz zu "Tabelleneinstellungen speichern" können mit "Gesamteinstellungen speichern" mehrere Tabellenaufbauten gespeichert und nach Wunsch geladen werden. Zusätzlich werden Sonderfunktionen der Tabelle (z.B. "Spalte gruppieren") ebenfalls bei der Speicherung bedacht.
