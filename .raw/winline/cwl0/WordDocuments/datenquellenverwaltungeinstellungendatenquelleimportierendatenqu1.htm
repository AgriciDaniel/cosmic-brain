Datenquellenverwaltung - Einstellungen / Datenquelle importieren / Datenquelle umwandeln / Vorlage importieren / Vorlage kopieren / Vorlage umwandeln

 

Mit Hilfe dieses Fensters der Datenquellenverwaltung können, abhängig vom zuvor gewählten Button, folgenden Arbeiten durchgeführt werden:

 

ü  Datenquellenverwaltung - Einstellungen
Es können individuelle Einstellung für die Anzeige und das Programmverhalten der Datenquellenverwaltung getroffenen werden.

 

ü  Datenquelle importieren
Volladministratoren oder Benutzer mit dem Teiladministrationsrecht "Datenadministration" können für die gewählte Auswertung eine zuvor exportierte Datenquelle importieren.

 

ü  Vorlage importieren
Eine zuvor exportierte Power Report-Vorlagen kann importiert werden.

 

ü  Datenquelle umwandeln
Volladministratoren oder Benutzer mit dem Teiladministrationsrecht "Datenadministration" können die aktuelle Datenquelle auf einen anderen Benutzer übertragen oder veröffentlichen.

 

ü  Vorlage kopieren
Die ausgewählte Vorlage kann auf andere Benutzer kopiert werden.

 

ü  Vorlage umwandeln
Der Datenquellen-Typ der ausgewählte Vorlage kann geändert werden.

 

Das Fenster wird je nach zu tätigender Arbeit unterschiedlich dargestellt und in den nachfolgenden Kapiteln detailliert beschrieben.
