Statuszeile

 

Die Statuszeile wird standardmäßig angezeigt und kann über das Menü "Anzeige" (Punkt "Statuszeile" -> es darf kein Fenster geöffnet oder es muss die Formularliste aktiv sein) aktiviert bzw. deaktiviert werden.

In der Zeile werden Informationen, bezogen auf das aktuelle Formular, angezeigt.

 

 

ü  Aktueller Arbeitsbereich
Je nachdem, in welchem Bereich der Fokus liegt, wird "Kopfbereich". "Mittelteil" oder "Fußbereich" angezeigt.

 

ü  Aktuelle Zeile
Wenn ein Element markiert wurde, wird dessen aktuelle Zeile angezeigt. Hierbei wird die Zeilennummer lt. Bereich und in Klammern die Zeile lt. Formularbeginn ausgewiesen. Sollte kein Element markiert sein wird die Position des Mauszeigers dargestellt.

 

ü  Aktuelle Spalte
Wenn ein Element markiert wurde, wird dessen aktuelle Spalte angezeigt. Sollte kein Element markiert sein wird die Position des Mauszeigers dargestellt.
