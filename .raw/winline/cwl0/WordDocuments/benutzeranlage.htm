Benutzeranlage

 

In Menüpunkt…

 

1  Benutzer

1  Benutzeranlage

 

… findet die Benutzeranlage statt bzw. können bestehende Benutzer bearbeitet werden.

 

 

Das Fenster ist in die folgenden zwei Register unterteilt, welche in den nachfolgenden Kapiteln detailliert beschrieben werden:

 

ü  Register "Stammdaten"
In diesem Register können neue Benutzer angelegt und bestehende editiert werden, wobei die Grundstammdaten zur Verfügung stehen.

 

ü  Register "Berechtigungen"
In diesem Register werden alle Berechtigungen des Benutzers verwaltet werden.
