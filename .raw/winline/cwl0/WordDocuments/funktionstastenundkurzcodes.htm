Funktionstasten und Kurzcodes

 

Innerhalb des CalcSheets stehen diverse Funktionstasten und Kurzcodes zur Verfügung.

 

Allgemein

Über die folgenden Funktionstasten und Kurzcodes können allgemeine Funktionen im WinCalc gesteuert werden:

 

Ø  F2

Bei Anwahl der Taste F2 wird die aktuelle Zelle editiert.

 

Ø  F5

Durch Anwahl der Taste F5 wird das aktuelle Fenster mit "Ok" bestätigt.

 

Ø  F9

Befindet man sich in einer Zelle des WinCalc, so wird bei Anwahl der Taste F9 eine Matchcode-Auswahl geöffnet.

 

Ø  ESC

Durch Anwahl der Taste "ESC" wird das aktuelle Fenster geschlossen.

 

Navigation

Über die folgenden Funktionstasten und Kurzcodes kann im CalcSheet navigiert werden:

 

Ø  Bild auf / Bild ab

Durch Anwahl von "Bild auf" bzw. "Bild ab" kann im CalcSheet gescrollt werden.

 

Ø  STRG + POS1 / STRG + ENDE

Mit Hilfe dieser Kurzcodes kann in die erste bzw. letzte Zelle des CalcSheets gesprungen werden.

 

Zwischenablage

Über die folgenden Funktionstasten und Kurzcodes kann im CalcSheet die Zwischenablage angesprochen werden:

 

Ø  STRG + A

Mit dieser Tastenkombination wird das gesamte CalcSheet markiert.

 

Ø  STRG + C

Durch diese Tastenkombination wird der markierte Zellenbereich in die Zwischenablage von Windows übernommen.

 

Ø  STRG + X

Durch "STRG + X" wird der markierten Zellenbereich in die Zwischenablage übergeben und zum Ausschneiden vorgesehen. Das Ausschneiden an sich findet erst beim Einfügen via "STRG + V" statt.

Hinweis

Bei einem Ausschneiden und Einfügen werden Zellverweise nicht angepasst. Ist dieses gewünscht, so muss das Verschieben via Drag & Drop vorgenommen werden.

 

Ø  STRG + V

Mit dieser Tastenkombination wird der Inhalt der Zwischenablage in das WinCalc übernommen.

 

Funktionen

Über die folgenden Funktionstasten und Kurzcodes können diverse Funktionen im CalcSheet angesprochen werden:

 

Ø  STRG + Z / STRG + Y

Mit Hilfe dieser Kurzcodes können die Buttons Rückgängig und Wiederholen ausgelöst werden.

 

Ø  STRG + PLUS (+) / STRG + MINUS (-)

Mit Hilfe dieser Kurzcodes können (abhängig vom Fokus) Zellen, Zeilen oder Spalten eingefügt bzw. gelöscht werden.

 

Ø  STRG + E

Durch Anwahl dieser Tastenkombination wird die Funktion Text aufteilen gestartet.

 

Ø  ALT + =

Mit Hilfe dieser Tastenkombination wird die Funktion Auto-SUMME ausgeführt.
