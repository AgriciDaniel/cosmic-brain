Individuelle Formulare

 

In einem Individuellen Formular stehen die Layout-Komponenten zur Verfügung. Dazu gibt es noch einen Bereich Felder, ob neben den Feldern der indiv. Vorlage auch noch folgende Optionen zur Verfügung stehen. Das individuelle Formular wird aus den "Individuellen Vorlagen" im Bereich Start, Vorlagen bereitgestellt. Die darin enthaltenen Formular-Komponenten entsprechen den im Kapitel FORM Felder (Formular) beschriebenen FORM Feldern.

 

mögliche Einstellungsdefinitionen für die Elemente innerhalb der individuellen Vorlagen:

Ø  Mehrzeilige Eingabe

Handelt es sich bei dem Datenfeld um ein Feld mit Langtext, so erfolgt die Darstellung automatisch in Form einer "Mehrzeiligen Eingabe". Die Zeilenanzahl der Eingabe wird hierbei automatisch mit 3 vorbelegt, kann aber individuell angepasst werden.

 

Ø  Dynamische Höhe

Bei einem Datenfeld mit Langtext kann die Höhe des Eingabefelds mit Hilfe dieser Option dynamisch wachsen. D.h. sobald die hinterlegte Zeilenanzahl überschritten wird, so erfolgt eine automatische Vergrößerung des Eingabefelds.

 

Ø  Zeilenanzahl

An dieser Stelle kann die Anzahl der Zeilen für eine mehrzeilige Eingabe hinterlegt werden.

 

Vorlage X Spalten

Wenn aus dem Formular vorher alle Elemente entfernt wurden, dann kann mit dieser Option ein 1/2/3-spaltiges Design übernommen werden, wobei das Programm die Felder automatisch gemäß dem Design anordnet.

 

Tabelle

Damit können Daten eines anderen FORMs in die WinLine-Stammdatenvorlage eingeblendet werden. Voraussetzung dafür ist, dass im FORM auch der referenzierende Datensatz enthalten ist, um eine Verknüpfung vornehmen zu können. Dabei können folgende Einstellungen vorgenommen werden. Die Buttons "KOPIEREN" und "LÖSCHEN" stehen zur Verfügung.

 

Ø  Höhe (min. 90)

Die Höhe der Tabelle kann hinterlegt werden. Es sind 150 voreingestellt. Mininum = 90.

 

Ø  FORM-Objekt

Über die Auswahlliste bzw. über die Autovervollständigung kann ein bestehendes FORM-Objekt ausgewählt werden, aus dem die Daten im aktuellen FORM angezeigt werden sollen.

 

Ø  Key-Spalte

Hier stehen alle Elemente der Typen "FORM-Schlüsselobjekt", "FORM-Objektauswahl" bzw. "WinLine-Objektauswahl" der im vorherigen Feld angegebenen FORM zur Verfügung. Anhand der Angabe dieses Objekts richtet sich der Inhalt der Tabelle. Wenn beispielsweise auf ein FORM-Schlüsselobjekt eines anderen FORM-Formulars verwiesen wird, kann das Element "FORM-Objektauswahl" des anderen FORM-Formulars eingebaut werden. Falls anschließend im Feld "FORM-Objektauswahl" im FORM DataCenter ein Datensatz ausgewählt wird, werden die zu diesen Datensatz passenden Daten innerhalb der Tabelle angezeigt.

 

Ø  Tabellen Modus

Mit der Einstellung "Ansichtstabelle" können die Datensätze in dieser Tabelle angezeigt werden, die Referenz zum Datensatz muss aber zuvor anhand eines Elements des Typs "FORM-Schlüsselobjekt" oder "FORM-Objektauswahl" ausgewählt werden, damit die Tabelle überhaupt befüllt wird. Mit der Einstellung "Steuerungstabelle" muss kein eigenes Element des Typs "FORM-Schlüsselobjekt" oder "FORM-Objektauswahl vorhanden sein, denn in dem Feld "Key-Spalte" unter dem Feld "Tabellen Modus" wird das Referenzfeld angegeben. Somit werden in dieser Tabelle direkt alle zur angegebenen Key-Spalte vorhandenen Datensätze dargestellt. Mittels Mausklick in dieser Tabelle können die einzelnen Zeilen in den Fokus genommen werden, damit beispielsweise in einer Ansichtstabelle, die zugehörigen Daten einer anderen FORM geladen werden.

 

Ø  editierbar

Wenn diese Option aktiviert ist, kann mittels einem Doppelklick in einem Feld innerhalb der Tabelle der Wert editiert bzw. abgeändert werden. Inhalte der angegebenen "Key-Spalte" können nicht editiert werden.

 

Ø  Filterbereich

Wenn unter der Überschriftenzeile der Tabelle eine Filtermöglichkeit vorhanden sein soll, kann diese Option aktiviert werden.

 

Ø  Button "SPALTEN BEARBEITEN"

Mit einem Klick auf den Button öffnet sich die Tabelle "Einstellungen". Diese Tabelle ist unterteilt in "DATENFELDER", "TABELLE", sowie "ALLE SPALTEN ENTFERNEN". In der "TABELLE" werden alle Spalten aus dem gewählten FORM-Objekt aufgezeigt. Durch Ziehen mit der Maus können einzelne Elemente und Einstellungen in den Bereich "DATENFELDER" aus der Tabelle genommen werden. Mit Hilfe des Buttons "ALLE SPALTEN ENTFERNEN" werden alle Einträge aus der Tabelle entfernt. Gespeichert werden diese Einstellungen über den Haken. Geschlossen wird die Einstellung über das X.
