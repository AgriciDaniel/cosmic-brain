Company Car Manager

 Example 1.1 – Company Car Manager Window

 Information is stored in a user-defined database table on

company cars used by individual employees.

 Information is managed in a new WinLine window that is called

up with a separate menu item.

 The car make, car licenes plate, and acquisition date is stored
for each existing company employee and displayed in a grid
control in the new window

 A report for the entered data can be printed to the screen or

the printer.
